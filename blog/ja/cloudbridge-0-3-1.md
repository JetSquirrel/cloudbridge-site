# 0.3.1: すべてを 1 つずつ

<p class="post-meta">2026-09-12&emsp;リリース&emsp;<a href="./">すべての記事</a></p>

0.3.0 はインターフェースを GPUI Kit の上に作り直しましたが、ページごとに作り直しました。各ページは新しい見た目を得て、同時にカードとは何か、プライマリボタンとは何か、テーブルヘッダーとは何かの自分用のコピーも持ちました。コピーはずれます。設定ページには作り直し前のスタイルがまだ残り、ほかの場所では同じ「3 つから 1 つ選ぶ」コントロールが 4 つの異なる形で現れていました。0.3.1 はデザインシステムを実体のあるものにする作業です。要素ごとに 1 つの定義をテーマに置き、すべてのページがそこから描画します。

## 重大度が目立ち具合を決める

この作業で、視覚的な階層が情報と矛盾している箇所が見つかりました。アカウントページでは、**正常**（何も求めていない唯一の状態）が最も明るいバッジを身にまとい、異常と残高不足はただのテキストとして描かれていました。アラートページでは、重大なアラートが警告より目立たない状態でした。どちらも正しく反転しました。状態が強ければスタイルも強くなり、アラートの赤と警告の黄は、中立的なラベルではなく実際のアラートのために取っておかれます。

同じ論理が操作にも適用されました。更新という安価で日常的な操作が概要のプライマリボタンになり、強制更新という高価な操作がセカンダリになりました。削除ボタンと削除の確認は危険のスタイルを使います。そしてアラートの操作ボタンは、リストのどこにあるかではなく、何をするかでスタイルが決まります。だから「却下」が最初に来たという理由だけで大きなプライマリボタンになることはありません。

## コンテンツを追い出さないエラー

以前はルールページのトグルが失敗すると、ルールリスト全体が赤いバナーで置き換えられていました。エラーはリストの上にインラインで表示され、リストはそのまま残り、すべてのエラーに「再試行」が用意されます。

## 小さな修正

- **「変動の大きい項目」**は支出の大きさではなく変化の大きさで並ぶようになりました。大きくても横ばいのサービスが永遠にリストを占めることはありません。
- ステータスバーの鮮度ドットは、次の取得が来るかどうかを反映します。最初の同期のあと永遠に緑のままではありません。
- **「今月解決したもの」**は、警告が上がった日ではなく解決した日を表示します。
- 円の金額に意味のない小数が表示されなくなりました。
- アカウントの詳細ページは SPEND / USAGE / CREDITS のカードを 1 つの SPEND カードにまとめ、合計を 1 行で分解します。
- ドキュメントサイトも同じ扱いを受けました。重複した見出しの改名、繰り返しの説明の重複排除、ハードコードされた色のデザイントークンへの移動です。

## 署名済みの macOS ビルド

macOS 向けのリリースビルドは CI で署名・公証されるようになりました。インストール手順にあった Gatekeeper の回避策（Control キーを押しながらクリック、「このまま開く」、`xattr` の行）は CloudBridge のインストールの一部ではなくなりました。DMG をダウンロードして Applications にドラッグするだけです。
