# 0.3.1: 모든 요소를 하나씩

<p class="post-meta">2026-09-12&emsp;릴리스&emsp;<a href="./">전체 글</a></p>

0.3.0은 인터페이스를 GPUI Kit 위에 다시 세웠지만, 페이지마다 따로 세웠습니다. 각 페이지는 새 모습을 얻었고, 동시에 카드, 기본 버튼, 표 머리글이 무엇인지에 대한 자기 복사본도 갖게 되었습니다. 복사본은 어긋납니다. 설정 페이지에는 아직 재구성 이전 스타일이 남아 있었고, 다른 곳에서는 같은 "셋 중 하나 고르기" 컨트롤이 네 가지 모양으로 나타났습니다. 0.3.1은 디자인 시스템을 실제로 만드는 작업입니다. 요소마다 정의는 하나, 테마 안에 있고, 모든 페이지가 그것을 가져다 씁니다.

## 심각도가 눈에 띄는 정도를 정합니다

이번 작업에서 시각적 위계가 정보와 어긋나는 곳들이 드러났습니다. 계정 페이지에서 **정상** — 아무것도 요구하지 않는 유일한 상태 — 이 가장 밝은 배지를 달고 있었고, 이상과 잔액 부족은 일반 텍스트로 표시됐습니다. 알림 페이지에서는 심각 알림이 경고보다 눈에 덜 띄었습니다. 둘 다 이제 올바르게 뒤집혔습니다. 상태가 강할수록 스타일도 강해지고, 알림 빨강과 경고 노랑은 중립적인 꼬리표가 아니라 실제 알림에만 씁니다.

같은 원칙이 동작에도 적용됐습니다. 일상적이고 값싼 작업인 새로 고침이 이제 개요의 기본 버튼이고, 값비싼 강제 새로 고침은 보조 버튼입니다. 삭제 버튼과 삭제 확인은 위험 스타일을 씁니다. 알림의 동작 버튼은 목록에서 어디에 놓였는지가 아니라 무엇을 하는지로 스타일이 정해지므로, "해제"가 첫 번째라는 이유만으로 커다란 기본 버튼이 되는 일은 없습니다.

## 내용을 밀어내지 않는 오류

규칙 페이지에서 토글 하나가 실패하면 규칙 목록 전체가 빨간 배너로 바뀌곤 했습니다. 이제 오류는 목록 위에 인라인으로 표시되고, 목록은 그대로 남으며, 모든 오류에 다시 시도가 붙습니다.

## 작은 수정 사항

- **"가장 크게 변한 항목"** 은 이제 지출 규모가 아니라 변화의 크기로 순위를 매깁니다. 크지만 평평한 서비스가 목록을 영원히 차지하지 않습니다.
- 상태 표시줄의 최신성 점은 첫 동기화 이후 계속 초록으로 남는 대신, 다음 가져오기가 예정되어 있는지를 반영합니다.
- **"이번 달 해결됨"** 은 알림이 발생한 날짜가 아니라 해결된 날짜를 보여 줍니다.
- 엔화 금액에 더 이상 의미 없는 소수가 표시되지 않습니다.
- 계정 상세 페이지는 SPEND / USAGE / CREDITS 카드를 하나의 SPEND 카드로 합치고, 총액을 한 줄로 나눠 보여 줍니다.
- 문서 사이트도 같은 처리를 받았습니다. 중복된 제목은 이름을 바꾸고, 반복된 설명은 하나로 합치고, 하드코딩된 색상은 디자인 토큰으로 옮겼습니다.

## 서명된 macOS 빌드

이제 macOS 릴리스 빌드는 CI에서 서명되고 공증됩니다. 설치 안내에 있던 Gatekeeper 우회 — Control-클릭, "그래도 열기", `xattr` 명령 — 는 CloudBridge를 설치하는 과정에서 사라집니다. DMG를 내려받아 응용 프로그램 폴더로 끌어다 놓으면 됩니다.

## 다음 계획

0.3.0과 같습니다. [로드맵](https://github.com/JetSquirrel/cloudbridge/blob/main/docs/roadmap.md)에는 아직 청구서 파일 *내보내기* 채널(S3 / OSS + Parquet), 명시적인 미할당 노드를 둔 태그 기반 배분, Volcengine, OpenAI, Anthropic의 청구 API가 남아 있습니다.
