# 0.4.0: 들어오는 길도, 읽는 방법도 더 많이

<p class="post-meta">2026-10-05&emsp;릴리스&emsp;<a href="./">전체 글</a></p>

0.3.0은 모든 청구서를 하나의 원장에 넣었고, 0.3.1은 인터페이스가 서로 어긋나지 않게 맞췄습니다. 0.4.0은 그 원장의 양쪽 끝을 다룹니다. 들어오는 쪽에서는 이제 AWS 계정이 Cost Explorer에 물어보는 대신 AWS가 S3에 써 두는 내보내기에서 청구서를 읽을 수 있습니다. 나가는 쪽에서는 이미 있는 데이터를 읽는 네 가지 방법이 새로 생겼습니다. 모델별로, 차원별로, 예산과 비교해서, 그리고 SQL로 보는 것입니다. 같은 애플리케이션이 이제 브라우저에서도 실행되므로, 아무것도 설치하기 전에 이 모든 것을 사용해 볼 수 있습니다.

## S3에서 읽는 AWS Data Exports

Cost Explorer는 합계로 답하고, 질문마다 요청 하나가 듭니다. AWS의 Data Exports(CUR 2.0, "FOCUS 1.2 with AWS columns" 형태)는 전체 청구서 — 리소스 ID, 태그, 각 행이 청구된 연결 계정 — 를 여러분이 소유한 S3 버킷에 씁니다. AWS 계정에 내보내기의 `s3://bucket/prefix` URI를 지정하면 새로 고침이 대신 그곳에서 읽습니다. Parquet이든 gzip으로 압축된 CSV든, 내보내기가 전달하도록 설정된 형식이면 됩니다.

쉽게 틀리지만 이번에 제대로 처리한 몇 가지가 있습니다.

- **한 달은 한 번만 셉니다.** "create new"로 설정된 내보내기는 전달물을 모두 나란히 쌓아 둡니다. CloudBridge는 해당 기간의 매니페스트가 가리키는 파일만 읽으므로, 9월을 열두 번 새로 고쳐도 여전히 9월 하나입니다.
- **전달되지 않은 것은 0이 아닙니다.** 아직 내보내기가 쓰지 않은 기간은 건너뛰며, 빈 달로 저장하지 않습니다.
- **지불자 계정의 내보내기는 멤버 계정별로 나뉩니다.** 각 행은 `SubAccountId`와 `SubAccountName`을 그대로 유지합니다.

S3 저장 및 요청 요금은 여전히 부과되고, Cost Explorer 정책은 S3 접근 권한을 주지 않습니다. [권한 페이지](https://cloudbridge.jetsquirrel.cloud/docs/permissions#aws-s3)에 내보내기 채널에 필요한 최소 정책이 있습니다. URI가 없는 계정은 계속 Cost Explorer를 사용합니다.

## Models 페이지

원장은 0.2.0부터 LLM 비용 옆에 토큰 수량을 저장해 왔지만, 아무것도 그것을 읽지 않았습니다. 새 Models 페이지가 읽습니다. 선택한 기간에 대해 각 모델의 비용과 증감, 입력·출력·캐시 토큰, 백만 토큰당 평균 비용과 캐시 비중을 보여 주고, 그 아래에 일별 토큰 차트가 붙습니다.

눈에 띄는 점도 알려 줍니다. 캐시 읽기가 입력 쪽의 5%에 못 미치는 모델은 캐시 가격으로 처리할 수 있었던 몫에 입력 가격을 내고 있는 것입니다. 모델 지출의 70% 이상을 한 모델이 차지하고 있다면 알아 둘 만합니다. 토큰 과금 없이 청구된 모델은 그렇게 표시합니다. 단가를 계산할 수 없기 때문입니다. 그리고 지출 증가는 두 기간의 토큰 수와 대조합니다. 늘어난 토큰이 증가를 설명하면 사용량이고, 설명하지 못할 때만 단가 상승으로 보고합니다.

Alibaba Cloud와 Volcengine 청구 항목 텍스트에 묻혀 있는 모델 이름은 아직 추출하지 않습니다. OpenAI, Anthropic, DeepSeek 가져오기는 모델을 직접 지정합니다.

## 원장을 읽는 다른 방법들

- **쿼리.** 로컬 DuckDB 원장 위에서 동작하는 읽기 전용 SQL 콘솔이며, 시작용 템플릿이 있습니다. 읽기 구문만 실행되고, 어쨌든 원장은 그 구문들을 위해 읽기 전용으로 열립니다. 데스크톱에서만 제공됩니다.
- **예산.** 규칙 페이지에 계정별 월 예산이 있고, "계정 예산" 규칙은 현재까지의 비용이나 월말 예상을 기준으로 비율 또는 금액에 대해 알립니다. 이제 이상 탐지 규칙도 특정 계정으로 한정할 수 있습니다.
- **차원별 분석.** 비용 귀속은 태그, 서비스, 리전, 서비스 분류 사이를 전환하며, 트리맵(면적은 비용, 색은 변화)이나 비중 막대로 그려지고, 옆에 해당 기간에 가장 비싼 리소스가 붙습니다. 계정 상세 페이지에도 같은 드릴다운이 있습니다.
- **데이터 상태.** 합계를 실제보다 믿기 어렵게 만드는 것들을 찾아 줍니다. 환율 표가 환산하지 못하는 통화, 귀속 태그나 리전이 없는 사용량, 어떤 청구 항목으로도 설명되지 않는 조정입니다. 하나를 무시하면 그 기간 동안은 계속 무시된 상태로 남습니다.

## 브라우저에서 실행되는 CloudBridge

이제 크레이트가 WebAssembly로도 빌드됩니다. [데모](https://cloudbridge.jetsquirrel.cloud/demo/)는 목업이 아닙니다. 페이지와 뷰 모델, 알림 규칙은 데스크톱의 코드 그대로이고, DuckDB, 서비스 API, 키링 대신 데모 청구서를 채운 인메모리 원장 위에서 실행됩니다. 쿼리, 규칙, 설정은 데스크톱에만 남고, Models 페이지를 포함한 나머지는 모두 그곳에 있습니다.

그 상태를 유지하려고 CI가 브라우저 버전을 필수 검사로 빌드하고, 두 빌드가 계산하는 통계 — 예상, 비교, 분해, 발견 사항 — 는 백엔드마다 복사본을 두는 대신 하나의 공유 모듈에 담아 테스트합니다.

## 작은 것들

- **계정을 삭제할 때 그 이력을 묻습니다.** 이전에는 청구 항목이 조용히 남아, 설명해 줄 계정도 없이 계속 합계에 포함됐습니다. 이제 삭제 대화상자에서 함께 지울지 묻고, 이전 삭제로 남은 이력은 계정 페이지에 표시되어 지울 수 있습니다.
- **어딘가로 이어지는 첫 실행.** 비어 있는 개요 화면에서 계정을 추가하거나 데모 청구서를 불러오도록 제안하고, API 계정을 저장하면 곧바로 청구서를 가져옵니다.
- **키보드 단축키.** ⌘1–⌘9로 페이지를 전환하고, ⌘R로 새로 고칩니다.
- **창이 먼저 열립니다.** 스토어는 열리고 페이지는 백그라운드에서, 각 페이지는 처음 방문할 때 불러옵니다.
- **지출 차트의 채우기**가 더 이상 차트를 가로질러 대각선 쐐기를 잘라 내지 않습니다.
- **보안:** rustls와 quick-xml을 세 건의 RUSTSEC 권고를 넘어서도록 올렸습니다.
- **Rust 1.95**가 선언된 최소 버전입니다. 이전 선언은 빌드가 되지 않는 값이었습니다.

## 다음 계획

[로드맵](https://github.com/JetSquirrel/cloudbridge/blob/main/docs/roadmap.md)은 청구서에서 그 뒤에 있는 리소스로 옮겨 갑니다. 먼저 S3 내보내기가 이미 제공하는 행에서 읽는 리소스별 비용이고, 다음은 리소스 사이의 관계 — 소유 구조를 따라 합산한 비용, 여전히 돈이 나가는 고아 리소스 — 입니다. Volcengine, OpenAI, Anthropic의 청구 API는 아직 남아 있습니다. 그때까지는 그 서비스들의 내보내기를 가져와 씁니다.
