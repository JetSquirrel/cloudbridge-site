# Raccourcis clavier

**[English](../shortcuts.md)**&emsp;**[中文](../zh/shortcuts.md)**&emsp;**[日本語](../ja/shortcuts.md)**&emsp;**[한국어](../ko/shortcuts.md)**&emsp;[Documentation](index.md)

Utilisez **⌘** sous macOS et **Ctrl** sous Windows. Les raccourcis de page
fonctionnent partout dans l’application, y compris quand un champ de texte a
le focus.

| Touches | Action |
| --- | --- |
| `⌘1` / `Ctrl+1` | Overview |
| `⌘2` / `Ctrl+2` | Alerts |
| `⌘3` / `Ctrl+3` | Attribution |
| `⌘4` / `Ctrl+4` | Query |
| `⌘5` / `Ctrl+5` | Accounts |
| `⌘6` / `Ctrl+6` | Rules |
| `⌘7` / `Ctrl+7` | Settings |
| `⌘8` / `Ctrl+8` | Détail d’un compte, sur le dernier compte affiché |
| `⌘9` / `Ctrl+9` | Models |
| `⌘0` / `Ctrl+0` | Insights |
| `⌘R` / `Ctrl+R` | Recharger la page courante |
| `⌘Enter` / `Ctrl+Enter` | Lancer la requête (page Query) |
| `Esc` | Fermer la boîte de dialogue ouverte ou le panneau de la barre des menus |

Recharger relit la page depuis le registre local ; cela ne récupère rien
auprès des fournisseurs. Dans la démo du navigateur, le navigateur peut
garder certaines de ces combinaisons de touches pour lui.
