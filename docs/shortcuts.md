# Keyboard shortcuts

**[中文](zh/shortcuts.md)**&emsp;[Docs](index.md)

Use **⌘** on macOS and **Ctrl** on Windows. The page shortcuts work from
anywhere in the app, including while a text field has focus.

| Keys | Action |
| --- | --- |
| `⌘1` / `Ctrl+1` | Overview |
| `⌘2` / `Ctrl+2` | Alerts |
| `⌘3` / `Ctrl+3` | Attribution |
| `⌘4` / `Ctrl+4` | Query |
| `⌘5` / `Ctrl+5` | Accounts |
| `⌘6` / `Ctrl+6` | Rules |
| `⌘7` / `Ctrl+7` | Settings |
| `⌘8` / `Ctrl+8` | Account detail, on the account it last showed |
| `⌘9` / `Ctrl+9` | Models |
| `⌘0` / `Ctrl+0` | Insights |
| `⌘R` / `Ctrl+R` | Reload the current page |
| `⌘Enter` / `Ctrl+Enter` | Run the query (Query page) |
| `Esc` | Close the open dialog or the menu bar panel |

Reloading re-reads the page from the local ledger; it does not fetch from
providers. In the browser demo, the browser may keep some of these key
combinations for itself.
