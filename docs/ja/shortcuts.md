# キーボードショートカット

**[English](../shortcuts.md)**&emsp;**[中文](../zh/shortcuts.md)**&emsp;**[한국어](../ko/shortcuts.md)**&emsp;**[Français](../fr/shortcuts.md)**&emsp;**[Español](../es/shortcuts.md)**&emsp;**[Deutsch](../de/shortcuts.md)**&emsp;**[Português](../pt/shortcuts.md)**&emsp;[ドキュメント](index.md)

macOS では **⌘**、Windows では **Ctrl** を使います。ページのショートカットは
アプリのどこからでも、テキストフィールドにフォーカスがある間でも動きます。

| キー | 動作 |
| --- | --- |
| `⌘1` / `Ctrl+1` | 概要 |
| `⌘2` / `Ctrl+2` | アラート |
| `⌘3` / `Ctrl+3` | コスト配賦 |
| `⌘4` / `Ctrl+4` | クエリ |
| `⌘5` / `Ctrl+5` | アカウント |
| `⌘6` / `Ctrl+6` | ルール |
| `⌘7` / `Ctrl+7` | 設定 |
| `⌘8` / `Ctrl+8` | アカウント詳細。最後に表示したアカウント |
| `⌘9` / `Ctrl+9` | モデル |
| `⌘0` / `Ctrl+0` | インサイト |
| `⌘R` / `Ctrl+R` | 現在のページを再読み込み |
| `⌘Enter` / `Ctrl+Enter` | クエリを実行（クエリページ） |
| `Esc` | 開いているダイアログまたはメニューバーのパネルを閉じる |

再読み込みはローカルの台帳からページを読み直すだけで、プロバイダーから取得
はしません。ブラウザデモでは、ブラウザがこれらのキーの組み合わせの一部を
自分用に確保する場合があります。
