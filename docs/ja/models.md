# モデル

**[English](../models.md)**&emsp;**[中文](../zh/models.md)**&emsp;**[한국어](../ko/models.md)**&emsp;**[Français](../fr/models.md)**&emsp;[ドキュメント](index.md)

モデルページは、ヘッダーで選んだ期間について、請求の LLM 側をモデルごとに
読みます。OpenAI、Anthropic、DeepSeek のアカウントは常に表示されます。他の
ソースの行は、Alibaba Cloud Model Studio、Volcengine、Amazon Bedrock の行の
ように、トークン課金の使用量を持つ場合に表示されます。モデルは請求の FOCUS
`ModelId`、または取り込みが名指すものです。Model Studio や Ark のように
どれも名指さない請求では、製品ごとにまとめます。

トークンは、プロバイダーのメーター名ではなく FOCUS のプロパティである
`TokenDirection` と `TokenCacheAction` で区別されます。そのため同じ種類の
トークンは、どの請求でも同じように読めます。
[FOCUS とトークンデータ](focus.md)を参照してください。

- 統計行には **AI spend**、合計 **tokens**、**blended $/1M**
  （コストを全トークンで割った、100 万トークンあたりの額）、**cache share**
  — 全入力トークンに占める、プロンプトキャッシュから読んだ入力トークンの
  割合（キャッシュへの書き込みを含む）— が表示されます。
- **Per model** には、各モデルのコストとその変化、IN、OUT、CACHE の
  トークン数、blended $/1M、モデル支出に占める割合が並びます。CACHE は
  キャッシュから読んだトークンです。IN は入力の残り、つまりキャッシュされて
  いない入力、キャッシュに書き込んだトークン、そして入力と出力をまとめて
  数える請求ではその合計です。どれを指すかはツールチップに表示されます。
  トークンはあるがコストのない行も、トークンの列には数えられます。月初来は、
  前月の同じ日数と比較され、前月全体とは比較されません。
- **Tokens per day** は日ごとのトークン量をグラフにします。

## 所見 {#findings}

- キャッシュの読み取りが入力側の 5% 未満のモデル — キャッシュ料金で済む
  ものに入力料金を払っています。入力と出力を分けない請求では指摘しません。
- モデル支出の 70% を超える 1 つのモデル。コストのあるモデルが 2 つ以上
  ある場合。
- 支出の増加を、2 期間のトークン数から見て使用量ではなく単価に帰せる場合。
- トークン課金のないまま請求されているモデル。単位コストを計算できません。

Alibaba Cloud と Volcengine の請求項目テキスト内のモデル名は、まだ抽出して
いません。
