# 概要とアカウント

**[English](../overview.md)**&emsp;**[中文](../zh/overview.md)**&emsp;**[한국어](../ko/overview.md)**&emsp;**[Français](../fr/overview.md)**&emsp;[ドキュメント](index.md)

## 概要 {#overview}

ヘッダーには期間の切り替え — **MTD**、**30d**、**12m** — があり、ページ上の
すべての数字は選んだ期間で計算されます。

- 見出しの **spend** はクレジット控除後の額です。実際に請求された金額です。
  その横に、総使用量と、それを下げたクレジットが表示されます。
- **chart**、変化率、**Where it went**、**biggest movers** は総使用量で
  動きます。使用量がクレジットで全額まかなわれるアカウントは純額がほぼ
  ゼロになり、その基準で描いた傾向はノイズです。
- **MTD** では、2 枚目のカードが現在のペースから月末を予測し、楽観と悲観の
  幅を示します。
- **Unallocated** は、どのビジネスラインにも届かない使用量の割合です。
  まだ説明できない請求の部分です。[コスト配賦](attribution.md)を参照して
  ください。

グラフにマウスを重ねると最も近い点に吸着し、そのバケットの日付と金額を
表示します。**Refresh** はデータが更新間隔より古いアカウントを取得し、
**Force Refresh** はすべてを取得します —
[かかる費用](aws.md#cost)を参照してください。

## 1 アカウントずつ見る {#account}

アカウントページでアカウント名をクリックすると、そのアカウントに踏み込めます。
同じ期間の切り替え、純額 / 総額 / クレジットの行、そのアカウントの使用量
の傾向、各サービスの割合と変化を示すサービス別の表があります。
[コスト配賦](attribution.md)と同じ次元の内訳もここにあります。

## アカウントの追加と削除 {#accounts}

追加するには、アカウントページでソースを選び、名前を入力し、API ソースなら
認証情報も入力して **Save** をクリックします。API ソースは今月と前月の請求を
すぐに取得します。その行の **Validate** は認証情報だけを単独で確認します。
プロバイダー自身のツールがマシン上に設定されている場合、フォームはコピーを
保存する代わりに、環境変数や CLI のプロファイルから認証情報を読めます。

アカウントを削除すると、必ずその行とキーリング内の認証情報が削除されます。
台帳にそのアカウントの課金項目がある場合は、ダイアログに **Also delete its
billing history** も表示され、既定ではオフです。オフのままなら課金項目は残り、
**すべての合計に数えられ続けます**。オンにすると、それらと背後にある生の
ペイロードが削除されます。どちらも元に戻せません。アカウントより長く残った
履歴は、アカウントページの **Billing history from deleted accounts** に
一覧表示され、**Delete history** で削除できます。

## データヘルス {#data-health}

CloudBridge は台帳を調べ、合計を実態より信頼できなくするものを探します。

- 為替レートテーブルが換算できない通貨の課金項目。
- `business_line` タグのない使用量。
- リージョンのない使用量。
- どの課金項目も説明しない調整。
- まだサービスカテゴリのない製品の使用量。

概要ページでは **Data quality** の帯として、アカウントページでは
**Data health** カードとして表示され、各アカウントのページにはその
アカウント自身のものが並びます。**Dismiss** はその請求期間について所見を
隠します。後の期間で同じ所見が現れれば、再び表示されます。

## 表示通貨 {#currency}

**Settings → Reporting** で USD か CNY を選びます。課金項目は請求された通貨を
保ち、日付付きの組み込み為替レートテーブルが表示用に換算します。レートは
課金日より後のものは使いません。レートはリアルタイムの市場データでは
ありません。レートがない場合は報告され、1:1 として扱われることはありません。
