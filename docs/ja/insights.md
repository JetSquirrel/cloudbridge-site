# インサイト

**[English](../insights.md)**&emsp;**[中文](../zh/insights.md)**&emsp;**[한국어](../ko/insights.md)**&emsp;**[Français](../fr/insights.md)**&emsp;**[Español](../es/insights.md)**&emsp;**[Deutsch](../de/insights.md)**&emsp;**[Português](../pt/insights.md)**&emsp;[ドキュメント](index.md)

インサイトは請求と実際に動いているものを突き合わせ、目を向ける価値のある
ものを一覧にします。それぞれに、この期間の請求から価格を付けます。

## セットアップとスキャン {#scan}

**Set up and scan** をクリックします。初回は、CloudBridge がリソース
スキャナーである
[corkscrew](https://github.com/JetSquirrel/corkscrew/tree/cloudbridge-dist)
のインストール前に確認を求めます。オープンソースで、私たちが保守する
フォークであり、約 45 MB、CloudBridge 自身のデータフォルダーに置かれ、
アプリに組み込まれたチェックサムと照合されます。その後、次のものを
スキャンします。

- 各 **AWS** アカウントを、そのアクセスキーで。AWS が既定で有効にする
  すべてのリージョン、または選んだリージョンだけで。
- 各 **Cloudflare** アカウントを、その API トークンで。

スキャンは読み取りだけを行い、リソースを一覧するだけで何も変更しません。
ただし認証情報にはリソースへの読み取りアクセスが必要です。
[AWS](aws.md#insights) と [Cloudflare](cloudflare.md#insights) を参照して
ください。**Scan again** はインベントリを更新します。スキャンには macOS
(Apple silicon) または Windows のデスクトップアプリが必要です。

## 見つかるもの {#findings}

AWS の場合：

- **停止したインスタンス** — ボリュームにまだ課金されているもの。
- **遊んでいるパブリックアドレス** — 割り当てられているが何にも
  アタッチされていない IPv4 アドレス。
- **持ち主のいないリソース** — 所有者タグ（`owner`、`team`、`project`、
  `cost-center`、`business_line`）がなく、管理するスタックやアプリもない
  もの。
- **課金されているがスキャンにないもの** — スキャンが対象としたリージョン
  内のもの。

価格を付けるにはリソースレベルの請求が必要です。
[Data Export](aws.md#data-exports)を指定した AWS アカウントです。それが
ない場合、所見は一覧表示されますが、価格は付きません。

Cloudflare の場合は、スキャンが見つけたものを種類ごとにカードで一覧します
— Workers、R2 バケット、D1 データベース、KV 名前空間、ゾーン、
Durable Objects — それぞれの種類とリソースの、請求に占める割合とこの期間の
使用量を、コストの高い順に示します。
[請求をリソースごとに分割](cloudflare.md#split)していれば、暴走している
名前空間やバケットが名前で見つかる場所です。

## セキュリティ設定 {#security}

CloudBridge 0.9.0 から、SSH または RDP をインターネット全体
（`0.0.0.0/0` または `::/0`）に開いている AWS セキュリティグループを、
独立したセクションが示します。スキャン結果を読むだけで、クラウド内の何も
変更せず、追加のデータフィードも必要としません。これはコンプライアンス
チェックでも完全なセキュリティレビューでもなく、その所見がコストの所見と
合算されることはありません。

各グループは **Finding**、**Not evaluated**、**Evaluated, no finding** の
いずれかで表示されます。行を開くと、確認されたルール、それが重要な理由、
手作業で確認すべきことが表示されます。公開ルールは露出の証拠ではありません。
そのグループが何かにアタッチされているかを確認してください。

**Not evaluated** は、インバウンドルールを読めなかったという意味であり、
そのグループが安全だという意味ではありません。スキャンがない場合、
部分的なスキャンの場合、またはグループを 1 つも一覧しなかったスキャンの
場合、このセクションは問題なしと読めるのではなく、その旨を明示します。

## まず要約 {#summary}

どのカードも、リソースの種類ごとの件数とコストから開きます。種類をクリック
するとそのリソースが一覧され、**Show more** で 50 件ずつ表示されます。もう
一度クリックすると閉じます。大きなアカウントも、求めない限り種類ごとに 1 行
のままです。

各所見には、コピーボタン付きの完全な ID、そのアカウント、そしてその課金項目
へのリンクが表示され、請求と照合できます。
