# トラブルシューティング

**[English](../troubleshooting.md)**&emsp;**[中文](../zh/troubleshooting.md)**&emsp;**[한국어](../ko/troubleshooting.md)**&emsp;**[Français](../fr/troubleshooting.md)**&emsp;[ドキュメント](index.md)

## macOS が Keychain へのアクセスを求める {#keychain}

保存された認証情報は CloudBridge 自身のファイルではなく OS のキーリングに
あるため、アプリが認証情報を読むときに、macOS が CloudBridge による
Keychain 項目の使用を許可するか尋ねることがあります。更新のたびに尋ねられない
よう **Always Allow** をクリックするか、毎回確認されたい場合は **Allow** を
クリックします。**Deny** をクリックすると、アプリは認証情報を読めず、
アクセスを許可するまでそのアカウントの取得は失敗します。

## AWS が AccessDenied を返す {#aws-access-denied}

キーの認証は成功していますが、そのユーザーに `ce:GetCostAndUsage` が
ありません。キーを所有する IAM ユーザーに
[Cost Explorer ポリシー](aws.md#cost-explorer)をアタッチしてください。
組織のサービスコントロールポリシーが Cost Explorer を拒否している場合も
あります。また AWS Organization では、メンバーアカウントは管理アカウントが
許可した場合にのみ Cost Explorer のデータを見られます。

## アカウントを追加した後に概要が空になる {#empty-overview}

- **まだ何も取得されていない。** 概要ページの **Refresh** をクリックします。
  ファイル取り込みのソース（Volcengine、OpenAI、Anthropic）には取得する
  ものがありません。代わりにその行の **Import** を使ってください。
- **プロバイダーがまだ報告していない。** プロバイダーは課金を遅れて公開します。
  AWS Cost Explorer は最大で約 24 時間遅れることがあるため、できたばかりの
  アカウントや今日の支出がすぐには現れない場合があります。Force Refresh は
  Cost Explorer のリクエスト料金がかかる場合があるので、それを使うのではなく
  後で再度試してください。
- **期間が狭すぎる。** 月の初めは **MTD** にほとんど何も入っていないことが
  あります。**30d** または **12m** に切り替えてください。
- **残高のみのソースである。** DeepSeek の API が報告するのは残高であり、
  支出ではありません。支出の内訳は使用量のダウンロードを取り込んでください。

## アカウントの更新が失敗し続ける {#refresh-failing}

メニューバーのパネルと概要ページには、失敗したアカウントとその理由が表示
されます。失敗したアカウントは 15 分後、次に 30 分後と再試行され、更新間隔まで
倍々に延びます。失敗し始めたときには通知が出ます。プロバイダーが応答したのに
CloudBridge が結果を保存できなかった場合（ディスク容量不足など）は、更新間隔の
中でその月を再度取得しないため、同じデータに対して二重に料金を払うことは
ありません。**Force Refresh** ならすぐに再試行します。
[メニューバーとバックグラウンド](background.md#failures)を参照してください。

## Windows SmartScreen がアプリをブロックする {#smartscreen}

Windows ビルドはコード署名されていないため、SmartScreen は
*Windows protected your PC* と表示します。ファイルが公式の
[Releases](https://github.com/JetSquirrel/cloudbridge/releases) ページから
来たことを確認したうえで、**More info**、続いて **Run anyway** をクリック
します。

## Windows でアプリと一緒にコンソールウィンドウが開く {#windows-console}

0.7.1 までの Windows リリースは、CloudBridge の隣に黒いコンソール
ウィンドウを開き、`.exe` には CloudBridge のアイコンではなく汎用のアイコンが
表示されます。そのコンソールを閉じると、通知領域のアイコンも含めて
CloudBridge が終了するため、閉じずに最小化してください。それ以降のリリースは
コンソールを開かず、アイコンは `.exe`、タイトルバー、タスクバーに表示されます。

## Windows でクエリがすべて失敗する {#windows-query}

Windows の 0.8.0 では、クエリページのクエリがすべて IO エラーで止まります。
ページが台帳ファイルを 2 回開くためです。CloudBridge 0.9.0 で
修正されています。データへの影響はありません。

## スキャナーのインストールが途中で止まる {#scanner-install}

インサイトのスキャナーは約 45 MB のダウンロードです。0.8.0 では、途中で
接続が切れると *io: unexpected end of file* と表示されてインストールが
止まります。**Set up and scan** をもう一度クリックしてください。0.9.0
以降は、ダウンロードの切断やタイムアウト、サーバーエラーを最大 3 回まで
自動で再試行します。

## 取り込みエラー {#import-errors}

- **"not UTF-8 text"** — Alibaba Cloud と Volcengine のコンソールは GBK の
  エクスポートを生成することがあります。UTF-8 で再エクスポートするか、
  取り込む前にファイルを CSV UTF-8 として保存してください。
- **認識されない列** — パーサーは中国語と英語のエクスポートで使われる既知の
  別名と、プロバイダーのフィールド名に一致させます。形式が変わっていたら、
  エラーと列ヘッダーを issue で報告してください。機密の値は伏せてください。
  伏せていない請求を添付しないでください。
- **取り込んだら月の金額が減った** — 取り込みは、そのアカウントについて
  ファイルが対象とするすべての月を置き換えるため、製品で絞り込んだ
  エクスポートではその製品だけが残ります。絞り込んでいない完全な請求を
  取り込み直してください。
- **トークン数はあるが支出がない** — 使用量のエクスポートには金額が
  含まれません。代わりにコストのエクスポートを取り込んでください。
  DeepSeek の場合は、`amount-*.csv` ではなくダウンロードした ZIP をそのまま
  取り込んでください。

## Cloudflare のスキャンが拒否される {#cloudflare-scan}

スキャンは、2 つのうちどちらが起きたかを示します。
*Cloudflare did not accept this account's API token* は、トークンが間違って
いるか期限切れです。アカウントページで確認してください。
*The token cannot read …* は、トークンは有効だがサービスの Read 権限が
不足しています。[Cloudflare](cloudflare.md#insights) に記載の権限を追加して
ください。権限がなくても請求は読めます。

## アラートが発火しない {#alert-silent}

- **Account budget ルールに測る対象の予算がない。** このルールは、
  **Monthly budget** のないアカウントでは、しきい値の種類にかかわらず
  何もしません。ルールページで設定してください。
- **支出がゼロから始まった。** コスト成長異常のルールは、サービスをその
  サービス自身の直近 7 日間と比較するため、コストがゼロだったサービスには
  基準がなく、決して発火しません。月末予測に基づく予算ルールがそのケースを
  カバーします。[暴走を捕まえる](cloudflare.md#runaway)を参照してください。
- **その日がまだ台帳にない。** ルールは取得済みのデータに対して実行されます。
  バックグラウンド更新は、CloudBridge が動作している間だけ、更新間隔ごとに
  アカウントを 1 回取得します。[メニューバーとバックグラウンド](background.md)
  を参照してください。
- **通知がオフ**であるか、アプリ起動時にアラートがすでにオープンでした。
  どちらの場合も、オープンなアラートはアラートページに一覧表示されます。
