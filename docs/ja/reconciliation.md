# 照合

**[English](../reconciliation.md)**&emsp;**[中文](../zh/reconciliation.md)**&emsp;**[한국어](../ko/reconciliation.md)**&emsp;**[Français](../fr/reconciliation.md)**&emsp;[ドキュメント](index.md)

**照合** ページは、1 つの問いに答えます。各プロバイダーの最終請求書は、
CloudBridge が取り込んだ内容と一致しているか。CloudBridge 0.9.0 以降が
必要です。

比較するのは、請求書自身の通貨での権威ある請求額だけなので、為替レートが
差異を隠すことはありません。請求書は課金項目とは別に保存され、課金項目を
変更することはありません。

## 請求書を追加する {#add}

- **Enter total** は 1 枚の請求書を記録します。**Total** は請求書の
  最終金額です。税、クレジット、調整は請求書に記載された内容であり、合計には
  加算されず、差異の説明に役立つだけです。クレジットは 0 または負の値で
  入力します。
- **Import invoice CSV** は多数の請求書を一度に読み込みます（デスクトップ版
  のみ）。1 行でも誤りがあれば何も取り込まれず、エラーはその行を示します。

CSV にはヘッダー行が必要です：

```csv
provider,account_id,billing_period,invoice_id,currency,amount,tax,credits,adjustments,billing_account_id
```

`tax` 以降の列は任意です。`billing_period` は `YYYY-MM`、`currency` は
3 文字の通貨コードで、金額は桁区切り記号のない数値です。各行は、あなたの
アカウントの 1 つを指している必要があります。

あるアカウントの課金項目が複数の請求アカウントにまたがる場合は、請求書の
請求アカウント ID を設定して、正しい請求アカウントと比較されるようにします。

## 結果を読む {#status}

| 状態 | 意味 |
| --- | --- |
| Matched | 請求書と台帳が、その通貨の許容範囲内で一致している |
| Difference | 一致していない。この行には差異と、次に確認すべきことが表示される |
| Cannot verify | まだ公平に比較できるものがなく、その理由が行に表示される |
| Missing evidence | その月に請求済みの課金項目はあるが請求書がないため、確認されていない |

ある月は、たとえばその月がまだ終わっていない、台帳に請求書の通貨の課金項目が
ない、またはすべての課金項目が金額のない使用量である場合に **Cannot verify**
と表示されます。推算または推定された金額は、台帳の金額から除外されます。

行を開くと、課金カテゴリ別の内訳、請求書の詳細、確認すべきことが
表示されます。たとえば、税が片側にしかない、クレジットや調整が遅れて
計上された、エクスポートが月の一部しか対象にしていない、合計が別の月に
合う、といったケースです。

## スナップショットと比較する {#snapshot}

**Compare with** では、現在の台帳または[月末スナップショット](overview.md#snapshots)
を選べます。そのため、後での更新が何を変えていても、締めたときの月に対して
請求書を確認できます。

請求書を削除しても、削除されるのはそのレコードだけです。台帳と
スナップショットはそのまま残ります。
