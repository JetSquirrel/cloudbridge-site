# Atajos de teclado

**[English](../shortcuts.md)**&emsp;**[中文](../zh/shortcuts.md)**&emsp;**[日本語](../ja/shortcuts.md)**&emsp;**[한국어](../ko/shortcuts.md)**&emsp;**[Français](../fr/shortcuts.md)**&emsp;**[Deutsch](../de/shortcuts.md)**&emsp;**[Português](../pt/shortcuts.md)**&emsp;[Documentación](index.md)

Usa **⌘** en macOS y **Ctrl** en Windows. Los atajos de página funcionan desde
cualquier parte de la aplicación, incluso mientras un campo de texto tiene el
foco.

| Teclas | Acción |
| --- | --- |
| `⌘1` / `Ctrl+1` | Overview |
| `⌘2` / `Ctrl+2` | Alerts |
| `⌘3` / `Ctrl+3` | Attribution |
| `⌘4` / `Ctrl+4` | Query |
| `⌘5` / `Ctrl+5` | Accounts |
| `⌘6` / `Ctrl+6` | Rules |
| `⌘7` / `Ctrl+7` | Settings |
| `⌘8` / `Ctrl+8` | Detalle de una cuenta, en la última cuenta que se mostró |
| `⌘9` / `Ctrl+9` | Models |
| `⌘0` / `Ctrl+0` | Insights |
| `⌘R` / `Ctrl+R` | Recargar la página actual |
| `⌘Enter` / `Ctrl+Enter` | Ejecutar la consulta (página Query) |
| `Esc` | Cerrar el diálogo abierto o el panel de la barra de menús |

Recargar vuelve a leer la página desde el registro local; no obtiene nada de los
proveedores. En la demo en el navegador, el navegador puede quedarse con algunas
de estas combinaciones de teclas.
