# 키보드 단축키

**[English](../shortcuts.md)**&emsp;**[中文](../zh/shortcuts.md)**&emsp;**[日本語](../ja/shortcuts.md)**&emsp;**[Français](../fr/shortcuts.md)**&emsp;[문서](index.md)

macOS에서는 **⌘**, Windows에서는 **Ctrl**을 씁니다. 페이지 단축키는 텍스트 필드에 포커스가 있을 때도 포함해 앱 어디서나 동작합니다.

| 키 | 동작 |
| --- | --- |
| `⌘1` / `Ctrl+1` | 개요 |
| `⌘2` / `Ctrl+2` | 알림 |
| `⌘3` / `Ctrl+3` | 비용 귀속 |
| `⌘4` / `Ctrl+4` | 쿼리 |
| `⌘5` / `Ctrl+5` | 계정 |
| `⌘6` / `Ctrl+6` | 규칙 |
| `⌘7` / `Ctrl+7` | 설정 |
| `⌘8` / `Ctrl+8` | 계정 상세, 마지막으로 보여 준 계정 |
| `⌘9` / `Ctrl+9` | 모델 |
| `⌘0` / `Ctrl+0` | 인사이트 |
| `⌘R` / `Ctrl+R` | 현재 페이지 새로 고침 |
| `⌘Enter` / `Ctrl+Enter` | 쿼리 실행(쿼리 페이지) |
| `Esc` | 열려 있는 대화 상자 또는 메뉴 막대 패널 닫기 |

새로 고침은 로컬 장부에서 페이지를 다시 읽으며 공급자에서 가져오지 않습니다. 브라우저 데모에서는 브라우저가 이 키 조합 일부를 자체적으로 가져갈 수 있습니다.
