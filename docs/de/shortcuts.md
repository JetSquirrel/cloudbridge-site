# Tastenkürzel

**[English](../shortcuts.md)**&emsp;**[中文](../zh/shortcuts.md)**&emsp;**[日本語](../ja/shortcuts.md)**&emsp;**[한국어](../ko/shortcuts.md)**&emsp;**[Français](../fr/shortcuts.md)**&emsp;**[Español](../es/shortcuts.md)**&emsp;**[Português](../pt/shortcuts.md)**&emsp;[Dokumentation](index.md)

Verwenden Sie **⌘** unter macOS und **Ctrl** unter Windows. Die Seitenkürzel
funktionieren überall in der App, auch während ein Textfeld den Fokus hat.

| Tasten | Aktion |
| --- | --- |
| `⌘1` / `Ctrl+1` | Übersicht |
| `⌘2` / `Ctrl+2` | Warnungen |
| `⌘3` / `Ctrl+3` | Zuordnung |
| `⌘4` / `Ctrl+4` | Abfrage |
| `⌘5` / `Ctrl+5` | Konten |
| `⌘6` / `Ctrl+6` | Regeln |
| `⌘7` / `Ctrl+7` | Einstellungen |
| `⌘8` / `Ctrl+8` | Kontodetails, beim zuletzt angezeigten Konto |
| `⌘9` / `Ctrl+9` | Modelle |
| `⌘0` / `Ctrl+0` | Einblicke |
| `⌘R` / `Ctrl+R` | Aktuelle Seite neu laden |
| `⌘Enter` / `Ctrl+Enter` | Die Abfrage ausführen (Seite Abfrage) |
| `Esc` | Den offenen Dialog oder das Menüleisten-Panel schließen |

Neu laden liest die Seite erneut aus dem lokalen Hauptbuch; es ruft nichts von
Anbietern ab. In der Browser-Demo behält der Browser einige dieser
Tastenkombinationen möglicherweise für sich.
