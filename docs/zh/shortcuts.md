# 键盘快捷键

**[English](../shortcuts.md)**&emsp;[文档](index.md)

macOS 上用 **⌘**，Windows 上用 **Ctrl**。页面快捷键在应用的任何地方都能用，包括文本框
处于焦点时。

| 按键 | 作用 |
| --- | --- |
| `⌘1` / `Ctrl+1` | Overview（总览） |
| `⌘2` / `Ctrl+2` | Alerts（告警） |
| `⌘3` / `Ctrl+3` | Attribution（成本归属） |
| `⌘4` / `Ctrl+4` | Query（SQL 查询） |
| `⌘5` / `Ctrl+5` | Accounts（账号） |
| `⌘6` / `Ctrl+6` | Rules（规则） |
| `⌘7` / `Ctrl+7` | Settings（设置） |
| `⌘8` / `Ctrl+8` | 账号详情，显示上次查看的账号 |
| `⌘9` / `Ctrl+9` | Models（模型） |
| `⌘0` / `Ctrl+0` | Insights（资源洞察） |
| `⌘R` / `Ctrl+R` | 重新加载当前页面 |
| `⌘Enter` / `Ctrl+Enter` | 执行查询（Query 页面） |
| `Esc` | 关闭当前对话框或状态栏面板 |

重新加载只是从本地账本重新读取页面，不会向云平台拉取数据。在浏览器演示里，浏览器
可能会占用其中一些组合键。
