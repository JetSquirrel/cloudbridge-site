# 账单核对

**[English](../reconciliation.md)**&emsp;[文档](index.md)

**账单核对** 页面回答一个问题：各服务商的最终发票与 CloudBridge 导入的数据是否一致？
需要 CloudBridge 0.9.0 或更高版本。

这里只比较发票币种下的权威账单金额，所以汇率不会掩盖差异。发票与费用分开存放，不会改动
你的费用数据。

## 添加发票 {#add}

- **录入总额** 记录一张发票。**总额** 是发票的最终金额。税费、抵扣和调整是发票上列明的
  内容，不会计入总额，只用于解释差异。抵扣请填零或负数。
- **导入发票 CSV** 可以一次导入多张，仅限桌面版。只要有一行有误，就不会导入任何内容，
  错误信息会指出是哪一行。

CSV 需要表头：

```csv
provider,account_id,billing_period,invoice_id,currency,amount,tax,credits,adjustments,billing_account_id
```

`tax` 及之后的列可选。`billing_period` 的格式是 `YYYY-MM`，`currency` 是三个字母的币种
代码，金额只用数字和小数点，不加千位分隔符。每一行都必须对应你已有的账号。

如果一个账号的费用涉及多个结算账户，请填写发票的结算账户 ID，以便与正确的账户比对。

## 看懂结果 {#status}

| 状态 | 含义 |
| --- | --- |
| 一致 | 发票和账本相符，差额在该币种的容差内 |
| 有差异 | 两者不符。这一行会显示差额和接下来要查什么 |
| 无法核实 | 目前还没有可以公平比较的数据，这一行会说明原因 |
| 缺少凭据 | 这个月已有账单费用但没有发票，因此尚未核对 |

比如这个月还没结束、账本里没有发票币种的费用，或所有费用都是没有金额的用量记录时，都会
显示 **无法核实**。推算或估算的金额不计入账本金额。

展开一行可以看到按费用类别的明细、发票详情和要查的内容，比如税费只出现在一侧、延后入账的
抵扣或调整、账单导出只覆盖部分月份，或总额其实对应另一个月。

## 与快照比对 {#snapshot}

**比对对象** 可以选当前账本或[月末快照](overview.md#snapshots)，这样可以拿发票和你结账时的
月份比对，不受之后刷新的影响。

删除发票只会删除这条记录，账本和快照都不受影响。
