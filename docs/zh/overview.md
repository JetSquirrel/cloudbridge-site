# 总览与账号

**[English](../overview.md)**&emsp;[文档](index.md)

## 总览 {#overview}

页头有一个时间范围切换——**MTD**（本月至今）、**30d** 或 **12m**——页面上的每个
数字都按你选的窗口计算。

- 最显眼的 **spend**（花费）是扣除抵扣后的净额：你实际被收了多少钱。旁边显示总用量
  和把它抵下来的抵扣金额。
- **图表**、变化百分比、**Where it went** 和 **biggest movers**（变化最大的服务）
  都按总用量计算。一个用量被抵扣全额覆盖的账号，净额接近零，在这个基数上画趋势只是噪声。
- 选 **MTD** 时，第二张卡片按当前消耗速度预测月底金额，并给出乐观和悲观区间。
- **Unallocated**（未归属）是没有落到任何业务线上的用量占比——也就是账单里你还解释
  不了的那部分。见[成本归属](attribution.md)。
- 如果时间范围内有费用没有汇率，会有警告说明它们未计入总额。

鼠标悬停在图表上会吸附到最近的点，显示该时间段的日期和金额。**Refresh** 拉取数据
早于刷新间隔的账号；**Force Refresh** 拉取全部账号——见[费用](aws.md#cost)。

## 逐个看账号 {#account}

在 **Accounts** 页面点账号名称即可进入详情：同样的时间范围切换，净额 / 总额 / 抵扣
一行数字，这个账号的用量趋势，以及每个服务的占比和变化。和[成本归属](attribution.md)
一样的维度拆分在这里也有。

## 导出月度成本回顾 {#report}

总览页的 **导出报告** 会把某个月保存成一个 HTML 文件，可以直接打印或分享。选择月份
（默认是最近一个已结束的月份），点 **选择文件并导出**，再选保存位置。文件不会从别处
加载任何内容，也不会上传到任何地方。需要 CloudBridge 0.9.0 或更高版本，而且只有
桌面版支持，浏览器演示版不能导出。

报告涵盖所有账号，金额用报告币种，不能按数据源或账号筛选。内容包括：

- 净成本、用量和抵扣，以及与上月相比的变化；
- **按服务的成本**、**按区域的净成本** 和 **按业务线的用量**；
- **预测与预算**，只针对进行中的月份；
- **数据健康**、主要的 **洞察** 和 **数据来源**，后者列出每个数据源的数据从哪里来、
  最近一次导入是什么时候；
- **这些数字未涵盖的内容**，比如没有汇率的费用、没有金额的用量记录，以及从未扫描或
  只扫描了一部分的资源清单。

进行中的月份显示的是月初至今的数字，不显示变化，因为上月一列是整月金额。报告里有
账号、服务和资源的名称，发给团队以外的人之前请先看一遍。

## 冻结一个月 {#snapshots}

账本一直在变：刷新或导入可能改写某个月，云平台也会在月底之后修正账单。账号详情页的
**月末快照** 会保留一份不再变化的副本，方便之后对账。需要 CloudBridge 0.9.0 或更高
版本。要拿副本和服务商发票比对，见[账单核对](reconciliation.md#snapshot)。

选择月份，点 **冻结本期**。对话框会说明这份副本包含多少条费用、合计多少。副本保留
这些费用、每种账单币种的合计、当时使用的汇率和账单来源，之后的刷新或导入都不会改动它。

- **与账本对比。** 每个修订都会显示 **与账本一致** 或 **与账本不一致**，并按账单币种、
  服务和费用类别列表。点一行可以查看背后的费用。差异按币种分别显示，汇率不会掩盖差异。
- **修订。** 账单变化后，点 **冻结为新修订** 会再存一份副本，之前的副本仍然保留。如果
  账单没有变化，就不会新增修订。
- **进行中的月份** 也可以冻结，但对话框会提示副本并不完整，之后快照也会一直这样提示。
- **缺少金额。** 如果某个月的费用只有用量没有金额，这个月就没有合计，但这不代表没有
  费用。卡片会说明这一点，也会说明有多少条费用没有金额或没有汇率。
- **核对副本。** 每个修订都显示快照 ID、导入批次和校验和。如果保存的费用行与校验和不再
  一致，卡片会提示不要依赖这个修订。

快照存放在 `billing.duckdb` 里，所以[备份](settings-and-data.md#backups)数据目录时
会一并备份。删除账号的账单历史时，快照也会一起删除。

## 添加和删除账号 {#accounts}

添加账号：进入 **Accounts**，选择数据源，填名字，API 类数据源再填凭据，然后点
**Save**。API 类数据源会立即拉取本月和上个月的账单；该行的 **Validate** 可以单独
校验凭据。如果这台电脑上已经配置好了云平台自己的命令行工具，表单可以直接从
环境变量或 CLI 配置文件读取凭据，而不必再存一份。

删除账号时，总会删除它这一行和钥匙串里的凭据。如果账本里还有它的费用记录，对话框
还会提供 **Also delete its billing history**（同时删除账单历史），默认不勾选。不勾选
时，这些费用会留在账本里，并**继续计入每一个总额**；勾选后，费用、背后的原始数据和
[月末快照](#snapshots)都会被删除。两种都无法撤销。账号删除后留下的历史，会列在 Accounts 页面的
**Billing history from deleted accounts** 下，在那里点 **Delete history** 可以删除。

## 数据健康 {#data-health}

CloudBridge 会检查账本里那些让总额看起来比实际更可靠的问题：

- 汇率表无法换算的币种；
- 没有 `business_line` 标签的用量；
- 没有区域的用量；
- 找不到对应费用的调整项；
- 来自尚未归类的产品的用量。

总览页以 **Data quality** 条显示，Accounts 页面以 **Data health** 卡片显示，账号详情页
列出该账号自己的问题。**Dismiss** 会在当前账期隐藏这条提示；下个账期出现同样的问题时
会再次显示。

## 报告币种 {#currency}

**Settings → Reporting** 可选 USD 或 CNY。每条费用保留它原本的计费币种；显示时用
内置的、带日期的汇率表换算，使用不晚于费用日期的汇率。汇率不是实时市场数据。缺少
汇率时会明确提示，绝不会按 1:1 处理。
