# Atalhos de teclado

**[English](../shortcuts.md)**&emsp;**[中文](../zh/shortcuts.md)**&emsp;**[日本語](../ja/shortcuts.md)**&emsp;**[한국어](../ko/shortcuts.md)**&emsp;**[Français](../fr/shortcuts.md)**&emsp;**[Español](../es/shortcuts.md)**&emsp;**[Deutsch](../de/shortcuts.md)**&emsp;[Documentação](index.md)

Use **⌘** no macOS e **Ctrl** no Windows. Os atalhos de página funcionam de
qualquer lugar do aplicativo, inclusive enquanto um campo de texto está em
foco.

| Teclas | Ação |
| --- | --- |
| `⌘1` / `Ctrl+1` | Visão geral |
| `⌘2` / `Ctrl+2` | Alertas |
| `⌘3` / `Ctrl+3` | Atribuição |
| `⌘4` / `Ctrl+4` | Consulta |
| `⌘5` / `Ctrl+5` | Contas |
| `⌘6` / `Ctrl+6` | Regras |
| `⌘7` / `Ctrl+7` | Configurações |
| `⌘8` / `Ctrl+8` | Detalhe da conta, na conta que ela mostrou por último |
| `⌘9` / `Ctrl+9` | Modelos |
| `⌘0` / `Ctrl+0` | Insights |
| `⌘R` / `Ctrl+R` | Recarregar a página atual |
| `⌘Enter` / `Ctrl+Enter` | Executar a consulta (página Consulta) |
| `Esc` | Fechar a caixa de diálogo aberta ou o painel da barra de menus |

Recarregar relê a página a partir do registro local; não busca nada nos
provedores. Na demonstração no navegador, o navegador pode reservar algumas
dessas combinações de teclas para si.
