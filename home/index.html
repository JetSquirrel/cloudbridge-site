See all your cloud and AI bills in one place.

CloudBridge is a desktop app that collects your bills from AWS, Alibaba Cloud, Cloudflare, OpenAI, Anthropic and DeepSeek, shows what you're spending on, and alerts you when costs jump. Everything is stored on your computer.

Free and open source. No sign-up, no sync, no telemetry. Also for Windows.

  • Alerts from the menu bar

  • Open source (MIT)

Get started

Get started in three steps

Install the app, then follow these steps. You don't need a server or an account.

  1. Add an account

    Enter a read-only API key for providers with a billing API, or just a name if you'll import files. Keys are saved in your system keyring.

Alerts

Alerts keep working after you close the window

When you close the window, CloudBridge stays in the menu bar and shows this month's spending. It refreshes each account on a schedule (once a day by default), checks your alert rules, and sends a notification if one is triggered. Turn on Open at login to keep it running after a restart.

Cost by resource

See what each bucket, Worker and Durable Object costs

Cloudflare's bill might say “R2 Class B operations, 734 on 3 October” without naming the bucket. CloudBridge gets each resource's daily usage from Cloudflare's analytics and splits the cost across them, so you can see which one is responsible. It also records usage inside the free allowance, because a cost problem can start there before you're charged anything.

Insights runs a read-only scan of your AWS and Cloudflare accounts and compares the results with your bill. It lists stopped instances whose volumes are still billed, idle public addresses, resources with no owner, and resources on the bill that the scan didn't find. Results are grouped by type with this period's cost, then listed by resource.

Data

All bills use the same columns

Bills are stored in the same format however they arrive, with column names from the FinOps FOCUS standard. Each charge keeps its original currency next to the converted amount. For example, an Alibaba Cloud ECS instance and an AWS EC2 instance both count as Compute, and you can query everything with SQL.

Query Attribution Models

SELECT provider, service_category,
       round(sum(billed_cost), 2) AS cost
FROM v_charge_normalized
WHERE billing_period = '2026-10'
GROUP BY ALL ORDER BY cost DESC;

Privacy

Your bills stay on your computer

Bills show what you run, who it's for and what it costs. CloudBridge keeps all of that on your computer.

  • Bills are stored in a DuckDB file on your disk and don't pass through any other server.
  • No account, no sync service and no telemetry.
  • Credentials are stored in the macOS Keychain or Windows Credential Manager.
  • Read-only: it never creates or changes anything at your provider.
  • It contacts each provider at most once per refresh interval and doesn't pay for the same data twice.
  • Open source under the MIT license, so you can read the code.

FAQ

Frequently asked questions

What is CloudBridge?

A free, open-source desktop app that collects your cloud and AI provider bills in a database on your computer, using each provider's billing API or a file you downloaded. It shows what you're spending on, checks your alert rules, and keeps running in the menu bar after you close the window.

Which providers does it support?

AWS (Cost Explorer, or a FOCUS Data Export in S3), Azure (Cost Management), Alibaba Cloud and Cloudflare through their billing APIs; Google Cloud through its BigQuery billing export; DeepSeek through its balance API; and bill exports from Alibaba Cloud, Volcengine, OpenAI, Anthropic and DeepSeek.

Does CloudBridge send my bills anywhere?

No. Bills go directly from the provider to a DuckDB file on your computer. There's no CloudBridge account, sync service or telemetry, and credentials are stored in your system keyring.

Will CloudBridge add to my bill?

Only on AWS, where Cost Explorer charges per request and S3 charges for reads. CloudBridge contacts each provider at most once per refresh interval (24 hours by default), which is about two Cost Explorer requests per AWS account a day. It doesn't repeat a fetch it has already paid for or download an unchanged S3 export again. The other APIs it calls are free, and it never creates or changes a resource.

How does it detect cost spikes?

It reads bills by day, so a spike shows up in the data the next day. Rules check for spending above its recent baseline, budgets and low balances. While CloudBridge is running, even with its window closed, it refreshes each account once a day and sends a notification for each alert. Cloudflare bills can also be split down to the bucket, Worker or Durable Object.

Which systems does it run on?

macOS on Apple silicon (signed and notarized) and 64-bit Windows. Linux and Intel Macs can build it from source.

Is CloudBridge free?

Yes. It's free and open source under the MIT license, with the full source code on GitHub. Any provider API fees are separate.

Can I try it without installing it?

Yes. The browser demo runs the same app, compiled to WebAssembly, on a sample bill covering twelve months and several providers.
