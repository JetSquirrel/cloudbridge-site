AWS、Azure、Google Cloud、Alibaba Cloud、Cloudflare を並べて

すべてのクラウドの請求書を 1 つの台帳に

CloudBridge は各クラウドの請求書を日次でお使いのコンピューター上の 1 つのデータベースに読み込み、同じ列と 1 つの報告通貨でまとめるので、サーバーを動かさずにすべてのクラウドの月次状況を確認できます。

macOS と Windows 向けの無料オープンソース。アカウントも同期もテレメトリもありません。

ソース

各クラウドの接続方法

どの接続も、課金に限定した読み取り専用の認証情報を使い、システムのキーチェーンに保存します。

クラウド方法得られる内容
AWS1 つのアクションの IAM ポリシーを使った Cost Explorer、または S3 上の FOCUS Data Exportサービスごと、日ごとのコスト。エクスポートならリソース ID とタグも

1 つの形式

すべての請求書が同じ列を使う

請求書はどの経路で届いても、FinOps の FOCUS 標準の列名で保存されます。たとえば Alibaba Cloud の ECS インスタンスと AWS の EC2 インスタンスはどちらも Compute として扱われ、1 つの SQL クエリですべてのプロバイダーを照会できます。

クエリ FOCUS とトークンデータ

  • billed_cost、effective_cost、service_category、region_id といった列は、どのソースでも同じ意味を持ちます。
  • 合計は 1 つの報告通貨で表示され、各明細は換算後の金額の隣に元の通貨を保持します。
  • クレジット、返金、単発の購入はそのままの区分で保持され、使用量に加算されません。
  • 台帳は DuckDB ファイルで、読み取り専用の SQL で照会したり、FOCUS CSV としてエクスポートしたりできます。

請求書を読む

誰が、何に使ったのか

概要画面には、月初来の支出、予測、すべてのソースをまたいだ変動の大きい項目が表示されます。帰属では支出を事業ラインに割り当て、タグ、サービス、リージョン、FOCUS のサービスカテゴリごとに分解できます。

概要 帰属 照合

  • アラートルールは同じ台帳で動きます。コスト異常、アカウント予算、残高の下限、タグなし支出。クラウド費用アラート。
  • モデルプロバイダーの請求書はクラウドの隣に並び、モデルごとの 100 万トークンあたりのコストを確認できます。LLM API のコスト管理。
  • 照合では、各プロバイダーの最終的な請求書と台帳を、請求書の通貨で比較します。

サーバー不要

デプロイするプラットフォームではなく、デスクトップアプリ

多くのマルチクラウド コスト管理ツールは、請求書を送るホスト型サービスか、自分でデプロイして運用するサーバーです。CloudBridge はインストールするアプリで、請求書はプロバイダーからディスク上のファイルへ直接届き、ほかのどこにも行きません。

CloudBridge と OptScale の比較

  • CloudBridge のアカウントも同期サービスもテレメトリもありません。
  • 読み取り専用：プロバイダー側のリソースは作成も変更もしません。
  • 1 人の請求書の見方のために作られています。共有ダッシュボードとロールが必要なチームには、FinOps サーバーのほうが適しています。
  • MIT のオープンソース。

FAQ

よくある質問

すべてのクラウドのコストをまとめて見るためにサーバーをデプロイする必要がありますか？

いいえ。CloudBridge は macOS と Windows 向けのデスクトップアプリです。読み取り専用の認証情報で各プロバイダーを読み取り、請求書をディスク上の DuckDB ファイルに保存します。用意するサーバー、データベース、アカウントはありません。

CloudBridge はどのクラウドを読み取りますか？

AWS、Microsoft Azure、Google Cloud、Alibaba Cloud、Cloudflare をそれぞれの課金 API またはエクスポート経由で、Volcengine を請求書のエクスポート経由で読み取ります。OpenAI、Anthropic、DeepSeek のモデルプロバイダーの請求書も同じ台帳に入ります。

通貨の異なる請求書はどう合算しますか？

合計は 1 つの報告通貨で表示されます。各明細は換算後の金額の隣に元の通貨を保持し、為替レートがない明細は推測せずに除外として報告します。

FOCUS とは何で、ここではなぜ重要ですか？

FOCUS は FinOps Foundation による課金データのオープンな仕様です。CloudBridge はその列名を採用しているので、Alibaba Cloud の ECS インスタンスと AWS の EC2 インスタンスはどちらも Compute として扱われ、1 つの SQL クエリですべてのプロバイダーを照会できます。台帳は FOCUS CSV としてエクスポートすることもできます。

CloudBridge はチーム全体向けの FinOps プラットフォームですか？

いいえ。1 人のコンピューター上の台帳で、同期も共有サーバーもありません。共有ダッシュボードやロールが必要な組織には FinOps サーバーのほうが適しています。CloudBridge と OptScale の比較の記事で両者を比べています。

請求書を読み取るのに費用はかかりますか？

プロバイダーが課金する場合のみです。AWS の Cost Explorer リクエストと S3 の読み取り、Google Cloud の BigQuery の無料枠を超えたクエリです。CloudBridge は各プロバイダーへ更新間隔ごとに最大 1 回（既定では 24 時間）しかアクセスしません。

クラウドの請求書を 1 か所にまとめる

CloudBridge をダウンロードし、クラウドごとにアカウントを追加すれば、すべてのクラウドの月次状況を確認できます。まずデモを見て回ることもできます。
