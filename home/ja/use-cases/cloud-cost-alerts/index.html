請求書が届く日ではなく、始まった日に気づく

請求書より先に届くクラウド費用アラート

CloudBridge は AWS、Alibaba Cloud、Cloudflare、モデルプロバイダーの請求書を日次でお使いのコンピューター上の台帳に読み込み、アラートルールを実行し、支出が跳ね上がったときにメニューバーから通知します。

CloudBridge をダウンロード アラートのドキュメントを読む

macOS と Windows 向けの無料オープンソース。アカウントも同期もテレメトリもありません。

請求書では遅すぎる理由

暴走する請求を不意打ちにする 3 つの要因

従量課金には上限がなく、請求書は使用量より遅れて届き、暴走するプロジェクトはたいてい誰も見ていないものです。

  1. 上限がない

    従量課金のアカウントは使った分だけ請求されます。壊れたコードは多くの場合クラッシュしません。成功し続け、課金され続けます。

  2. 遅れて届く請求書

    使用量は集計され、価格が付いてから請求書に届きます。Cost Explorer は 1 日遅れることがあり、請求書は月に 1 回です。

  3. 誰も見ていない

    本番環境にはダッシュボードがあります。テストプロジェクトや忘れられたプロトタイプにはトラフィックがないので、誰もそのグラフを見ません。

アラートルール

請求のつまずき方ごとに 1 つのルール

3 つのルールが有効な状態で用意されています。重要なアカウントには予算ルールを追加し、必要なら異常検知ルールを 1 つのアカウントに絞り込めます。

DeepSeek のような前払い残高が急速に減る残高の下限残高の通貨で 200、またはアカウントの予算

見守る

ウィンドウを閉じても見張り続けます

macOS と Windows では、CloudBridge は今月の支出をタイトルにしたメニューバーに残ります。更新間隔（既定は 24 時間、最短 6 時間）が過ぎたアカウントを取得し、ルールを実行し、新しいアラートごとにシステム通知を出します。「ログイン時に開く」を有効にすると、再起動後も続きます。

メニューバーとバックグラウンド

  • 請求書は日次で読み込まれるので、急増は月末ではなく翌日に現れます。
  • Cloudflare の日次請求は R2 バケット、Worker、D1 データベース、Durable Object まで分割されます。
  • 15 分ごとのローカルチェックで、プロバイダーに問い合わせずに更新時期を検知します。
  • 各プロバイダーへの問い合わせは更新間隔ごとに最大 1 回なので、頻繁に見守っても追加の API 料金はかかりません。

実際の事例

10,811 ドルの Durable Object アラート

休眠していた Cloudflare プロジェクトが約 6 兆回の読み取りと書き込みをループし、最初の兆候は請求書でした。記事では、何が起きたのか、なぜ誰も警告を受けなかったのか、どのルールなら気づけたのかを解説しています。

記事を読む

  • 異常検知ルールでは捉えられません。コストが 0 のサービスには基準値がないからです。
  • 月末予測に基づくアカウント予算ルールなら、最初の高額な日から捉えられます。
  • Cloudflare の無料枠内の使用量もコスト 0 として記録します。暴走はそこから始まるからです。

プライバシー

請求書はお使いのマシンに残ります

請求書には、何を誰のために動かしているかが書かれています。CloudBridge は台帳をディスク上の DuckDB ファイルに、認証情報を OS のキーチェーンに保持し、プロバイダーに対しては読み取りしか行いません。

  • CloudBridge のアカウントも同期サービスもテレメトリもありません。
  • 読み取り専用の認証情報。プロバイダーのリソースは作成も変更もしません。
  • MIT のオープンソース。

FAQ

よくある質問

CloudBridge はどのくらい早くコストの急増に気づきますか？

1〜2 日以内です。請求書は日次で読み込まれるため、プロバイダーがその日の使用量を報告し、次の更新が走れば台帳に反映されます。月次の請求書を待つ必要はありません。ただしリアルタイムの監視ではありません。

アラートを送るために CloudBridge を開いておく必要がありますか？

起動している必要はありますが、ウィンドウを開いておく必要はありません。macOS と Windows ではメニューバーに残り、更新間隔ごとに各アカウントを更新して、新しいアラートごとに通知を出します。「ログイン時に開く」を有効にすれば、再起動後も動き続けます。

支出がゼロだったプロジェクトの暴走も捉えられますか？

はい、月末予測に基づくアカウント予算ルールで捉えられます。異常検知ルールはサービスをその過去 7 日間と比較するため、コストが 0 だったサービスには基準値がありません。予測ルールは最初の高額な日をその月の残りに投影します。

請求書を見張ることで請求額は増えますか？

AWS のみ増える可能性があります。Cost Explorer はリクエストごとに、S3 は読み取りに対して課金されます。CloudBridge は更新間隔ごとに各アカウントを 1 回取得し（既定では AWS アカウントあたり 1 日およそ 2 回の Cost Explorer リクエスト）、同じデータに二度払いすることはありません。

翌月ではなく、翌日に気づく

CloudBridge をダウンロードし、アカウントを接続し、予算を設定すれば、あとはメニューバーから見張ってくれます。まずデモを見て回ることもできます。
