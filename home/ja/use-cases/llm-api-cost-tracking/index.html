仕組み

コンソールのエクスポートからトークンあたりコストまで

OpenAI と Anthropic の API キーは不要です。コンソールから取得できるエクスポートで十分です。

  1. エクスポートをダウンロード

    OpenAI：Usage → Export。Anthropic：Usage または Cost → Export。DeepSeek：Usage → Download。

  2. 取り込む

    名前だけで認証情報なしのアカウントを追加し、その行の「取り込み」をクリックします。同じ月をもう一度取り込むと置き換わります。

  3. モデルページを見る

    各モデルのコストと変化、入力・出力・キャッシュのトークン数、100 万トークンあたりのコストを確認できます。

ソース

読み取るモデルの請求書

トークンで計測された明細はどのソースからでもモデルページに表示されます。モデル名は請求書に書かれているとおりです。

モデルページ

モデルごとのトークン経済性

統計行には AI 支出、合計トークン数、100 万トークンあたりの混合コスト、キャッシュ比率が表示されます。その下に、各モデルのコストと変化、入力・出力・キャッシュのトークン数とモデル支出に占める割合、日次トークン数のグラフが続きます。

モデル デモで試す

  • キャッシュ読み取りが入力側の 5% 未満のモデルを指摘します。キャッシュ料金で済むはずのものを入力料金で払っている状態です。
  • モデル支出の 70% 以上を 1 つのモデルが占めている場合に指摘します。
  • 単価の上昇と使用量の増加を区別します。
  • トークン計測なしで請求されているモデルを指摘します。その単価は計算できません。

見守る

モデル支出が跳ね上がったときに気づく

コスト増加の異常検知ルールは、日次支出が直近 7 日間の基準値を 2 日連続で上回るソースとサービスを指摘します。残高下限ルールは、DeepSeek のような前払い残高が尽きる前に警告します。CloudBridge はどちらもメニューバーから通知します。

クラウド費用アラート

  • モデル支出は AWS、Alibaba Cloud、Cloudflare と同じ台帳にあるので、概要 1 ページですべて把握できます。
  • 元の通貨は換算後の金額の隣に保持されます。為替レートがない場合は推測せず、報告します。
  • 台帳はディスク上の DuckDB ファイルで、クエリページから読み取り専用の SQL を実行できます。

FAQ

よくある質問

CloudBridge に OpenAI や Anthropic の API キーを渡す必要がありますか？

いいえ。OpenAI と Anthropic は取り込み専用です。名前だけで認証情報なしのアカウントを追加し、プロバイダーのコンソールからダウンロードしたコストまたは使用量のエクスポートを取り込みます。

エクスポートにトークン数だけで金額がない場合は？

トークンだけのエクスポートは使用量の記録として残ります。CloudBridge はモデルページでトークンを集計しますが、推定の請求額に変換することはありません。

どのモデルプロバイダーを読み取りますか？

OpenAI と Anthropic のエクスポート、DeepSeek の残高 API と使用量のダウンロード、Alibaba Cloud の請求書経由の Alibaba Cloud Model Studio、Volcengine の請求書エクスポート経由の Volcengine Ark です。

モデル支出が跳ね上がったときに警告してくれますか？

はい。コスト増加の異常検知ルールが、日次支出が直近 7 日間の基準値を連日上回る場合に指摘し、残高下限ルールが DeepSeek のような前払い残高の不足を警告します。

モデルごとの請求額を確認

CloudBridge をダウンロードし、先月のエクスポートを取り込んで、モデルページを開いてください。まずデモを見て回ることもできます。
