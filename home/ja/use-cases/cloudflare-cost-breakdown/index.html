請求書に書かれるのはサービス名で、リソース名ではありません

Cloudflare の請求額の裏側にある Worker、バケット、Durable Object を特定

CloudBridge は Cloudflare の日次の課金使用量を読み取り、R2 バケット、Worker、D1 データベース、Durable Object のネームスペースごとに 1 日ごとの請求額を分割して、お使いのコンピューター上の台帳に記録します。

CloudBridge をダウンロード Cloudflare のドキュメントを読む

macOS と Windows 向けの無料オープンソース。アカウントも同期もテレメトリもありません。

仕組み

API トークンからリソース別のコストまで

読み取り専用のトークンが 1 つあれば十分です。トークンはシステムのキーチェーンに保存されます。

  1. トークンを作成

    Account → Billing → Read を持つカスタム API トークンを作成します。リソース別の分割には Account → Account Analytics → Read も追加します。

  2. アカウントを追加

    アカウント ID とトークンを入力します。CloudBridge が課金使用量（サービスごと、日ごとの支出）を読み取ります。

  3. 分割結果を確認

    1 日ごとの請求額が、そのメーターを使ったリソースに按分されます。インサイトには各リソースの割合と、今期間の使用量が表示されます。

分割

何を、何に対して分割するか

Cloudflare の請求書には「R2 Class B operations, 734 on 3 October」とだけ書かれているかもしれません。CloudBridge は GraphQL Analytics API に問い合わせて、どのバケットがその操作を行ったのかを特定します。

請求書の項目分割の対象基準
R2 の Class A / Class B オペレーション、ストレージR2 バケットそのメーターに対する各バケットの使用量
Workers のリクエストと CPUWorker各 Worker のリクエスト数
D1 の読み取り・書き込み行数、ストレージD1 データベースそのメーターに対する各データベースの使用量
Durable Objects のリクエスト、実行時間、行数、ストレージDurable Object のネームスペースそのメーターに対する各ネームスペースの使用量

リソース別に分割 →

数値の意味

合計は請求額と一致します

分割は Cloudflare が請求した金額を分けるだけで、価格を新たに作ることはありません。分析データはサンプリングされ、無料枠は特定のリソースではなくアカウントに属するため、各行は推定値として表示されます。

インサイト トークンの権限

  • KV や Queues のように分析データで分割できないメーターは、アカウント単位の行としてそのまま残ります。
  • 無料枠内の使用量もコスト 0 として記録します。暴走はそこから始まるからです。
  • Account Analytics の権限がなくても請求書は読み取れます。分割されないだけです。
  • 対象は従量課金（セルフサーブ）アカウントのみです。Cloudflare の課金使用量 API はアルファ版で、Enterprise には対応していません。

暴走の発見

Worker がループし始めた最初の日に気づく

従量課金の Cloudflare アカウントには、支出上限で停止する仕組みがありません。アカウントに月次予算を設定し、月末予測に基づくアカウント予算ルールを追加してください。最初の高額な日が月全体に投影され、それを読み取った最初の更新でアラートが発火します。

暴走を捉える クラウド費用アラート

  • 実際の事例：休眠していたプロジェクトの Durable Object アラームが、誰も気づかないうちに 10,811 ドル請求されました。記事を読む。
  • 更新間隔を 6 時間に短縮し、「ログイン時に開く」を有効にして CloudBridge をメニューバーに常駐させます。
  • アラートが発火したら、インサイトで各 Worker とネームスペースの割合が表示されるので、原因の 1 つが浮かび上がります。

プライバシー

請求書はお使いのマシンに残ります

台帳はディスク上の DuckDB ファイルで、トークンは OS のキーチェーンに保存されます。CloudBridge は Cloudflare から読み取るだけで、請求書は AWS、Azure、Google Cloud、モデルプロバイダーの請求書と同じ列に並びます。

  • CloudBridge のアカウントも同期サービスもテレメトリもありません。
  • 読み取り専用のトークン。Cloudflare アカウント側で何かが作成・変更されることはありません。
  • MIT のオープンソース。

FAQ

よくある質問

Cloudflare の請求書には、Worker や R2 バケットごとのコストが表示されますか？

いいえ。請求書はサービス単位で止まります。その日に請求された R2 Class B オペレーションや Durable Object の行数は分かっても、どのバケットやネームスペースが使ったのかは分かりません。CloudBridge は Cloudflare の GraphQL Analytics API から各リソースの使用量を読み取り、その割合で 1 日ごとの請求額を分割します。

リソース別の分割はどのくらい正確ですか？

各部分の合計は Cloudflare が請求した金額と一致し、推定値として表示されます。Cloudflare の分析データはサンプリングされており、無料枠は特定のリソースではなくアカウントに属します。

API トークンにはどの権限が必要ですか？

請求書の読み取りに「Account, Billing, Read」、分割に「Account, Account Analytics, Read」が必要です。どちらも読み取り専用です。インサイトのリソーススキャンにはさらにいくつかの Read 権限が必要で、拒否された権限はその旨が表示されます。

Cloudflare Enterprise アカウントでも使えますか？

いいえ。Cloudflare の課金使用量 API は従量課金（セルフサーブ）アカウントのみを対象としており、まだアルファ版の API です。CloudBridge は Enterprise アカウントを未対応として報告します。

CloudBridge は暴走した Worker や Durable Object を停止できますか？

いいえ。読み取りのみを行います。高額な日を読み取った最初の更新でアラートを出し、インサイトで請求の原因となっている Worker やネームスペースを表示するので、Cloudflare のダッシュボードで停止できます。

Cloudflare のリソースごとのコストを確認

CloudBridge をダウンロードし、Cloudflare アカウントを追加して、インサイトを開いてください。まずデモを見て回ることもできます。
