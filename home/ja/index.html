ダウンロード

クラウドと AI の請求書を、一か所で。

CloudBridge は、AWS、Azure、Google Cloud、Alibaba Cloud、Cloudflare、OpenAI、Anthropic、DeepSeek の請求書を集め、何にいくら使っているかを表示し、コストが急増したときに知らせるデスクトップアプリです。データはすべてお使いのコンピューターに保存されます。

Mac 版をダウンロード デモを試す

無料のオープンソース。登録も同期もテレメトリもありません。 Windows 版もあります。

  • データは DuckDB にローカル保存
  • メニューバーからアラート
  • macOS と Windows
  • オープンソース（MIT）

はじめかた

3 つのステップではじめる

アプリをインストールしたら、次の手順に進みます。サーバーもアカウントも必要ありません。

  1. アカウントを追加

    課金 API があるプロバイダーでは、読み取り専用の API キーを入力します。ファイルを取り込むだけなら名前だけでかまいません。キーはお使いのシステムのキーチェーンに保存されます。

    ソースCloudflareアカウント ID023e105f…c353API トークン••••••••••••保存

  2. 請求書を取り込む

    CloudBridge はプロバイダーから請求書を取得することも、ダウンロードしたファイルを取り込むこともできます。どちらも FOCUS 標準の列名を持つ同じ形式になります。

    • APIAWS 2026-10127 件
    • APICloudflare 2026-1014 件
    • ファイルOpenAI 2026-09412 件

  3. コストを確認してアラートを設定

    アカウント、サービス、モデル、事業ラインごとに支出を分解できます。コストが急増すると通知が届きます。

まず画面を見てみたい場合は、空の概要画面にある デモデータを読み込む を選ぶか、サンプルの請求書を使った ブラウザデモ をお試しください。

Windows では、インストーラーにコード署名がないため、SmartScreen の警告が表示される可能性があります。対処方法ははじめかたをご覧ください。

アラート

ウィンドウを閉じてもアラートは動き続けます

ウィンドウを閉じても、CloudBridge はメニューバーに残って今月の支出を表示します。各アカウントをスケジュール（既定では 1 日 1 回）で更新し、アラートルールを評価して、条件に合えば通知を送ります。再起動後も動かし続けるには「ログイン時に開く」を有効にしてください。

リソース別コスト

データ

すべての請求書が同じ列を使う

請求書はどの経路で届いても同じ形式で保存され、列名は FinOps の FOCUS 標準に従います。各明細は換算後の金額の隣に元の通貨を保持します。たとえば Alibaba Cloud の ECS インスタンスと AWS の EC2 インスタンスはどちらも Compute として扱われ、すべてを SQL で照会できます。

クエリ 帰属 モデル

SELECT provider, service_category,
       round(sum(billed_cost), 2) AS cost
FROM v_charge_normalized
WHERE billing_period = '2026-10'
GROUP BY ALL ORDER BY cost DESC;

プライバシー

請求書はお使いのコンピューターに残ります

請求書には、何を動かし、誰のためで、いくらかかったかが書かれています。CloudBridge はそのすべてをコンピューター上に保持します。

  • 請求書はディスク上の DuckDB ファイルに保存され、ほかのサーバーを経由しません。
  • アカウントも同期サービスもテレメトリもありません。
  • 認証情報は macOS のキーチェーンまたは Windows の資格情報マネージャーに保存されます。
  • 読み取り専用：プロバイダー側で何かを作成したり変更したりすることはありません。
  • 各プロバイダーへのアクセスは更新間隔ごとに最大 1 回で、同じデータに二度払いしません。
  • MIT ライセンスのオープンソースなので、コードを読むことができます。

ユースケース

よくあるユースケース

  • クラウド費用のアラートAWS、Cloudflare、AI API の請求が急に増えたときに、請求書を待たずに気づけます。
  • マルチクラウドのコストダッシュボードAWS、Azure、Google Cloud、Alibaba Cloud、Cloudflare の請求書を、サーバーを動かさずに 1 つの台帳にまとめます。
  • Cloudflare コストの内訳どの Worker、R2 バケット、D1 データベース、Durable Object が Cloudflare の請求額の原因なのかを確認できます。
  • LLM API のコスト管理OpenAI、Anthropic、DeepSeek、Model Studio の各モデルのトークンあたりコストを、手元にあるエクスポートから確認できます。

FAQ

よくある質問

CloudBridge とは何ですか？

クラウドと AI プロバイダーの請求書を、お使いのコンピューター上のデータベースに集める無料のオープンソースデスクトップアプリです。各プロバイダーの課金 API か、ダウンロードしたファイルを使います。何にいくら使っているかを表示し、アラートルールを評価し、ウィンドウを閉じた後もメニューバーで動き続けます。

どのプロバイダーに対応していますか？

AWS（Cost Explorer、または S3 上の FOCUS Data Export）、Azure（Cost Management）、Alibaba Cloud、Cloudflare は課金 API 経由。Google Cloud は BigQuery の課金エクスポート経由。DeepSeek は残高 API 経由。さらに Alibaba Cloud、Volcengine、OpenAI、Anthropic、DeepSeek の請求書エクスポートに対応しています。

CloudBridge は請求書をどこかに送信しますか？

いいえ。請求書はプロバイダーから、お使いのコンピューター上の DuckDB ファイルへ直接届きます。CloudBridge のアカウントも同期サービスもテレメトリもなく、認証情報はシステムのキーチェーンに保存されます。

CloudBridge によって請求額は増えますか？

AWS のみ増える可能性があります。Cost Explorer はリクエストごとに、S3 は読み取りに対して課金されます。CloudBridge は各プロバイダーへ更新間隔ごとに最大 1 回（既定では 24 時間）しかアクセスしないため、AWS アカウントあたり 1 日およそ 2 回の Cost Explorer リクエストになります。支払い済みの取得を繰り返したり、変更のない S3 エクスポートを再ダウンロードしたりはしません。その他の API は無料で、リソースの作成や変更も一切行いません。

コストの急増はどう検知しますか？

請求書を日次で読み込むため、急増は翌日のデータに現れます。ルールは直近の基準値に対する支出超過、予算、残高不足をチェックします。CloudBridge の実行中は、ウィンドウを閉じていても各アカウントを 1 日 1 回更新し、アラートごとに通知を送ります。Cloudflare の請求はバケット、Worker、Durable Object まで分割することもできます。

どのシステムで動きますか？

Apple シリコンの macOS（署名・公証済み）と 64 ビット Windows です。Linux と Intel Mac ではソースからビルドできます。

CloudBridge は無料ですか？

はい。MIT ライセンスの無料オープンソースで、ソースコードは GitHub にあります。プロバイダーの API 利用料は別途かかります。

インストールせずに試せますか？

はい。ブラウザデモ では、同じアプリを WebAssembly にコンパイルし、12 か月・複数のプロバイダーにわたるサンプル請求書で動かしています。

アプリをダウンロードし、アカウントを追加するか請求書を取り込めば、今月のコストが分かります。まずデモを試すこともできます。
