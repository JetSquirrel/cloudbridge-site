하나의 형식

모든 청구서를 같은 열에

청구서는 어떻게 들어오든 FinOps FOCUS 표준의 열 이름으로 저장됩니다. Alibaba Cloud ECS 인스턴스와 AWS EC2 인스턴스는 모두 Compute로 집계되고, SQL 쿼리 하나로 모든 공급자를 다룰 수 있습니다.

쿼리 FOCUS와 토큰 데이터

  • billed_cost, effective_cost, service_category, region_id 같은 열은 모든 소스에서 같은 의미입니다.
  • 합계는 하나의 기준 통화로 표시되고, 각 청구 항목은 환산 금액 옆에 원래 통화를 함께 보관합니다.
  • 크레딧, 환불, 일회성 구매는 사용량에 더하지 않고 그 자체로 보관합니다.
  • 원장은 DuckDB 파일이라 읽기 전용 SQL로 조회하거나 FOCUS CSV로 내보낼 수 있습니다.

청구서 읽기

누가, 무엇에 썼는지

개요 화면은 이번 달 누적, 예상, 모든 소스에서 가장 크게 변한 항목을 보여 줍니다. 귀속은 지출을 사업 부문에 연결하고, 태그, 서비스, 리전, FOCUS 서비스 분류별로 나눠 줍니다.

개요 귀속 대사

  • 알림 규칙은 같은 원장 위에서 실행됩니다. 비용 이상, 계정 예산, 잔액 하한, 태그 없는 지출. 클라우드 비용 알림.
  • 모델 서비스 청구서는 클라우드 옆에 모델별 백만 토큰당 비용과 함께 놓입니다. LLM API 비용 추적.
  • 대사는 각 공급자의 최종 인보이스를 인보이스 통화로 원장과 비교합니다.

서버 없음

배포하는 플랫폼이 아니라 설치하는 앱

대부분의 멀티 클라우드 비용 도구는 청구서를 보내야 하는 호스팅 서비스이거나, 직접 배포하고 유지해야 하는 서버입니다. CloudBridge는 설치하는 앱이라, 청구서는 공급자에서 여러분의 디스크에 있는 파일로만 가고 그 밖으로 나가지 않습니다.

CloudBridge vs OptScale

  • CloudBridge 계정도, 동기화 서비스도, 텔레메트리도 없습니다.
  • 읽기 전용입니다. 공급자 쪽에서 리소스를 만들거나 바꾸지 않습니다.
  • 한 사람이 청구서를 보는 용도로 만들어졌습니다. 공유 대시보드와 역할이 필요한 팀에는 FinOps 서버가 더 맞습니다.
  • MIT 라이선스 오픈소스입니다.

FAQ

자주 받는 질문

모든 클라우드 비용을 한곳에서 보려면 서버를 배포해야 하나요?

아니요. CloudBridge는 macOS와 Windows용 데스크톱 앱입니다. 읽기 전용 자격 증명으로 각 공급자의 청구서를 읽어 여러분의 디스크에 있는 DuckDB 파일에 보관합니다. 준비할 서버도, 데이터베이스도, 계정도 없습니다.

CloudBridge는 어떤 클라우드를 읽나요?

AWS, Microsoft Azure, Google Cloud, Alibaba Cloud, Cloudflare를 각자의 청구 API나 내보내기로 읽고, Volcengine은 청구서 내보내기로 읽습니다. OpenAI, Anthropic, DeepSeek의 모델 서비스 청구서도 같은 원장에 들어옵니다.

서로 다른 통화의 청구서를 어떻게 합산하나요?

합계는 하나의 기준 통화로 표시됩니다. 각 청구 항목은 환산 금액 옆에 원래 통화를 함께 보관하며, 환율이 없는 청구 항목은 임의로 환산하지 않고 합계에서 빠졌다고 알려 줍니다.

FOCUS가 무엇이고, 여기서 왜 중요한가요?

FOCUS는 FinOps Foundation이 만든 청구 데이터 공개 사양입니다. CloudBridge는 그 이름을 따라 열을 정의하므로, Alibaba Cloud ECS 인스턴스와 AWS EC2 인스턴스가 모두 Compute로 집계되고 SQL 쿼리 하나로 모든 공급자를 다룰 수 있습니다. 원장은 FOCUS CSV로 내보낼 수도 있습니다.

CloudBridge는 팀 전체를 위한 FinOps 플랫폼인가요?

아니요. 한 사람의 컴퓨터에 있는 원장이며, 동기화도 공유 서버도 없습니다. 조직에 공유 대시보드와 역할 관리가 필요하다면 FinOps 서버가 더 맞습니다. CloudBridge vs OptScale 글에서 둘을 비교합니다.

청구서를 읽는 데 비용이 드나요?

공급자가 요금을 받는 경우에만 듭니다. AWS Cost Explorer 요청과 S3 읽기, 그리고 월 무료 한도를 넘는 Google Cloud BigQuery 쿼리입니다. CloudBridge는 새로 고침 주기(기본 24시간)마다 각 공급자에 최대 한 번만 요청합니다.

클라우드 청구서를 한곳에 모으세요

CloudBridge를 내려받아 클라우드마다 계정을 추가하고, 모든 클라우드의 이번 달을 확인하세요. 먼저 데모를 둘러봐도 좋습니다.
