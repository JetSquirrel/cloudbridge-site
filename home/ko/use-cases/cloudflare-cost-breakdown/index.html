청구서에는 서비스만 적히고 리소스는 적히지 않습니다

Cloudflare 청구서 뒤에 있는 Worker, 버킷, Durable Object를 확인하세요

CloudBridge는 Cloudflare의 하루 단위 과금 사용량을 읽어, 각 청구 금액을 R2 버킷, Worker, D1 데이터베이스, Durable Object 네임스페이스별로 나눠 여러분의 컴퓨터에 있는 원장에 담습니다.

CloudBridge 다운로드 Cloudflare 문서 읽기

macOS와 Windows용 무료 오픈소스. 계정도, 동기화도, 텔레메트리도 없습니다.

작동 방식

API 토큰에서 리소스별 비용까지

읽기 전용 토큰 하나면 충분합니다. 토큰은 시스템 키링에 보관됩니다.

  1. 토큰 만들기

    Account → Billing → Read 권한을 가진 사용자 지정 API 토큰입니다. 리소스별 분할에는 Account → Account Analytics → Read를 추가하세요.

  2. 계정 추가

    계정 ID와 토큰을 입력합니다. CloudBridge가 서비스별·일별 과금 사용량을 읽습니다.

  3. 분할 결과 읽기

    하루의 청구 금액을 그 미터를 쓴 리소스별로 나눕니다. Insights는 각 리소스의 비중과 이번 기간의 사용량을 보여 줍니다.

나눈 부분의 합은 청구서와 같습니다

분할은 Cloudflare가 청구한 금액을 나누는 것이지, 가격을 새로 만들지 않습니다. 분석이 샘플링되고 무료 한도는 특정 리소스가 아니라 계정에 속하기 때문에, 각 행은 추정치로 표시됩니다.

Insights 토큰 권한

  • KV나 Queues처럼 분석이 나눌 수 없는 미터는 계정 단위의 한 행으로 통째로 남습니다.
  • 무료 한도 안의 사용량도 비용 0으로 기록합니다. 폭주는 바로 거기서 시작되기 때문입니다.
  • Account Analytics 권한이 없어도 청구서는 읽습니다. 다만 분할되지 않습니다.
  • 종량제 계정만 지원합니다. Cloudflare의 과금 사용량 API는 알파 단계이며 Enterprise는 대상이 아닙니다.

폭주 잡아내기

Worker가 루프를 돌기 시작한 첫날에 알아채세요

종량제 Cloudflare 계정은 지출 한도에서 멈춰 주지 않습니다. 계정에 월 예산을 지정하고 월말 예상을 기준으로 한 Account budget 규칙을 추가하세요. 비용이 발생한 첫날이 남은 달 전체로 투영되고, 그날을 읽는 첫 새로 고침에서 알림이 발동합니다.

폭주 잡아내기 클라우드 비용 알림

  • 실제 사례: 잠자던 프로젝트의 Durable Object 알람이 아무도 모르는 사이에 10,811달러를 청구했습니다. 글 읽기.
  • 새로 고침 간격을 6시간으로 줄이고, '로그인 시 열기'를 켠 채 CloudBridge를 메뉴 막대에 두세요.
  • 알림이 발동하면 Insights가 각 Worker와 네임스페이스의 비중을 보여 주므로, 원인인 것이 눈에 띕니다.

프라이버시

청구서는 여러분의 컴퓨터에 남습니다

원장은 디스크의 DuckDB 파일이고 토큰은 OS 키링에 있습니다. CloudBridge는 Cloudflare에서 읽기만 하며, 이 청구서는 AWS, Azure, Google Cloud, 모델 서비스의 청구서와 같은 열에 나란히 놓입니다.

  • CloudBridge 계정도, 동기화 서비스도, 텔레메트리도 없습니다.
  • 읽기 전용 토큰이며, Cloudflare 계정에서 무엇도 만들거나 바꾸지 않습니다.
  • MIT 라이선스 오픈소스입니다.

FAQ

자주 받는 질문

Cloudflare 청구서에 Worker나 R2 버킷별 비용이 나오나요?

아니요. 청구서는 서비스에서 멈춥니다. 하루에 R2 Class B 작업이 몇 건, Durable Object 행이 몇 개 청구되었는지는 알려 주지만, 어느 버킷이나 네임스페이스가 그것을 썼는지는 알려 주지 않습니다. CloudBridge는 Cloudflare의 GraphQL Analytics API에서 리소스별 사용량을 읽고, 그 비중으로 하루의 청구 금액을 나눕니다.

리소스별 분할은 얼마나 정확한가요?

나눈 부분의 합은 Cloudflare가 청구한 금액과 같으며, 추정치로 표시됩니다. Cloudflare의 분석은 샘플링되고, 무료 한도는 특정 리소스가 아니라 계정에 속하기 때문입니다.

API 토큰에는 어떤 권한이 필요한가요?

청구서에는 Account, Billing, Read가, 분할에는 Account, Account Analytics, Read가 필요합니다. 둘 다 읽기 전용입니다. Insights의 리소스 스캔에는 Read 권한이 몇 가지 더 필요하며, 어떤 권한이 거부되었는지 알려 줍니다.

Cloudflare Enterprise 계정에서도 동작하나요?

아니요. Cloudflare의 과금 사용량 API는 종량제(self-serve) 계정만 다루며 아직 알파 API입니다. CloudBridge는 Enterprise 계정을 지원 대상이 아니라고 보고합니다.

CloudBridge가 폭주하는 Worker나 Durable Object를 멈출 수 있나요?

아니요. 읽기만 합니다. 비용이 큰 날을 읽는 첫 새로 고침에서 알릴 수 있고, Insights가 어느 Worker나 네임스페이스가 그 청구의 원인인지 보여 주므로 Cloudflare 대시보드에서 멈출 수 있습니다.

Cloudflare 리소스마다 드는 비용을 확인하세요

CloudBridge를 내려받아 Cloudflare 계정을 추가하고 Insights를 열어 보세요. 먼저 데모를 둘러봐도 좋습니다.
