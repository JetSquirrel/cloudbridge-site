동작 방식

콘솔 내보내기에서 토큰당 비용까지

OpenAI나 Anthropic의 API 키는 필요 없습니다. 각 콘솔이 제공하는 내보내기 파일이면 충분합니다.

  1. 내보내기 파일 받기

    OpenAI: Usage → Export. Anthropic: Usage 또는 Cost → Export. DeepSeek: Usage → Download.

  2. 가져오기

    계정을 이름만으로 추가하고 자격 증명은 넣지 않은 다음, 해당 행에서 가져오기를 누릅니다. 같은 달을 다시 가져오면 기존 데이터를 교체합니다.

  3. Models 페이지 확인

    모델별 비용과 증감, 입력·출력·캐시 토큰, 백만 토큰당 비용을 보여 줍니다.

모델별 토큰 경제성

상단 요약에는 AI 지출, 전체 토큰, 백만 토큰당 평균 비용, 캐시 비중이 표시됩니다. 그 아래에는 모델별 비용과 증감, 입력·출력·캐시 토큰과 모델 지출에서 차지하는 비중, 그리고 일별 토큰 차트가 이어집니다.

모델 데모에서 사용해 보기

  • 캐시 읽기가 입력 쪽의 5%에 못 미치는 모델을 표시합니다. 캐시 가격으로 처리할 수 있었던 몫에 입력 가격을 내고 있는 경우입니다.
  • 모델 지출의 70% 이상을 차지하는 모델을 표시합니다.
  • 단가 상승과 사용량 증가를 구분해 알려 줍니다.
  • 토큰 과금 없이 청구된 모델을 짚어 줍니다. 단가를 계산할 수 없는 경우입니다.

계속 지켜보기

모델 지출이 급증할 때 바로 알기

비용 증가 이상 탐지 규칙은 일별 지출이 최근 7일 기준선을 이틀 연속 넘는 소스와 서비스를 표시합니다. 잔액 하한 규칙은 DeepSeek 같은 선불 잔액이 바닥나기 전에 경고합니다. 두 알림 모두 메뉴 막대에서 알려 줍니다.

클라우드 비용 알림

  • 모델 지출이 AWS, Alibaba Cloud, Cloudflare와 같은 원장에 있어 개요 화면 하나로 모두 볼 수 있습니다.
  • 원래 통화는 환산 금액 옆에 보관되고, 환율이 없으면 추정하지 않고 보고합니다.
  • 원장은 디스크의 DuckDB 파일이며, 쿼리 페이지에서 읽기 전용 SQL을 실행할 수 있습니다.

FAQ

자주 받는 질문

CloudBridge에 OpenAI나 Anthropic API 키를 줘야 하나요?

아니요. OpenAI와 Anthropic은 가져오기만 지원합니다. 계정을 이름만으로 추가하고 자격 증명은 넣지 않은 다음, 서비스 콘솔에서 내려받은 비용 또는 사용량 내보내기를 가져오면 됩니다.

내보내기에 토큰만 있고 비용이 없으면 어떻게 되나요?

토큰만 있는 내보내기는 사용량 기록으로 남습니다. CloudBridge는 Models 페이지에서 그 토큰을 집계하지만, 추정 청구서로 바꾸지는 않습니다.

어떤 모델 서비스를 읽나요?

OpenAI와 Anthropic의 내보내기, DeepSeek의 잔액 API와 사용량 다운로드, Alibaba Cloud 청구서를 통한 Alibaba Cloud Model Studio, Volcengine 청구서 내보내기를 통한 Volcengine Ark입니다.

모델 지출이 급증하면 알려 주나요?

네. 비용 증가 이상 탐지 규칙은 일별 지출이 최근 7일 기준선을 연속으로 넘을 때 표시하고, 잔액 하한 규칙은 DeepSeek 같은 선불 잔액이 얼마 남지 않았을 때 경고합니다.

모델 청구서를 모델별로 확인하세요

CloudBridge를 내려받아 지난달 내보내기를 가져오고 Models 페이지를 열면 됩니다. 먼저 데모를 둘러봐도 좋습니다.
