다운로드

모든 클라우드와 AI 청구서를 한곳에서.

CloudBridge는 AWS, Azure, Google Cloud, Alibaba Cloud, Cloudflare, OpenAI, Anthropic, DeepSeek의 청구서를 모아 무엇에 얼마를 쓰는지 보여 주고, 비용이 급증하면 알려 주는 데스크톱 앱입니다. 모든 데이터는 여러분의 컴퓨터에 저장됩니다.

Mac용 다운로드 데모 체험하기

무료 오픈소스입니다. 가입도, 동기화도, 텔레메트리도 없습니다. Windows용도 있습니다.

  • 데이터는 DuckDB에 로컬 저장
  • 메뉴 막대에서 알림
  • macOS와 Windows
  • 오픈소스(MIT)

시작하기

세 단계로 시작하기

앱을 설치한 뒤 아래 단계를 따르면 됩니다. 서버도 계정도 필요 없습니다.

  1. 계정 추가

    청구 API가 있는 서비스는 읽기 전용 API 키를 입력하고, 파일만 가져올 서비스는 이름만 입력하면 됩니다. 키는 시스템 키링에 저장됩니다.

    소스Cloudflare계정 ID023e105f…c353API 토큰••••••••••••저장

  2. 청구서 가져오기

    CloudBridge가 서비스에서 직접 청구서를 가져올 수도 있고, 직접 내려받은 파일을 가져올 수도 있습니다. 두 경우 모두 FOCUS 표준의 열 이름을 쓰는 같은 형식으로 저장됩니다.

    • APIAWS 2026-10청구 127건
    • APICloudflare 2026-10청구 14건
    • 파일OpenAI 2026-09청구 412건

  3. 비용 확인과 알림 설정

    계정, 서비스, 모델, 사업 부문별로 지출을 나눠 볼 수 있습니다. 비용이 급증하면 알림을 받습니다.

먼저 둘러보고 싶다면? 비어 있는 개요 화면에서 Load demo data(데모 데이터 불러오기)를 선택하거나, 샘플 청구서로 브라우저 데모를 사용해 볼 수 있습니다.

Windows에서는 설치 파일에 코드 서명이 없어 SmartScreen 경고가 표시될 수 있습니다. 대처 방법은 시작하기를 참고하세요.

알림

창을 닫아도 알림은 계속 작동합니다

창을 닫으면 CloudBridge는 메뉴 막대에 남아 이번 달 지출을 보여 줍니다. 정해진 일정(기본 하루 한 번)에 따라 각 계정을 새로 고치고 알림 규칙을 확인해, 규칙이 발동하면 알림을 보냅니다. 재시작 후에도 실행되게 하려면 '로그인 시 열기'를 켜 두세요.

리소스별 비용

데이터

모든 청구서가 같은 열을 씁니다

청구서는 어떻게 들어오든 같은 형식으로 저장되며, 열 이름은 FinOps의 FOCUS 표준을 따릅니다. 각 청구 항목은 환산 금액 옆에 원래 통화를 함께 보관합니다. 예를 들어 Alibaba Cloud ECS 인스턴스와 AWS EC2 인스턴스는 모두 Compute로 집계되고, 모든 데이터를 SQL로 조회할 수 있습니다.

쿼리 귀속 모델

SELECT provider, service_category,
       round(sum(billed_cost), 2) AS cost
FROM v_charge_normalized
WHERE billing_period = '2026-10'
GROUP BY ALL ORDER BY cost DESC;

프라이버시

청구서는 여러분의 컴퓨터에 그대로 남습니다

청구서에는 무엇을 운영하는지, 누구를 위한 것인지, 얼마가 드는지가 담겨 있습니다. CloudBridge는 그 모든 정보를 여러분의 컴퓨터에 보관합니다.

  • 청구서는 디스크의 DuckDB 파일에 저장되며 다른 서버를 거치지 않습니다.
  • 계정도, 동기화 서비스도, 텔레메트리도 없습니다.
  • 자격 증명은 macOS 키체인 또는 Windows 자격 증명 관리자에 저장됩니다.
  • 읽기 전용입니다. 서비스 쪽에서 무엇도 만들거나 바꾸지 않습니다.
  • 새로 고침 주기마다 각 서비스에 최대 한 번만 요청하며, 같은 데이터를 두 번 결제하지 않습니다.
  • MIT 라이선스 오픈소스이므로 코드를 직접 읽어 볼 수 있습니다.

활용 사례

자주 쓰는 활용 사례

  • 클라우드 비용 알림AWS, Cloudflare, AI API 청구서가 급증할 때 인보이스를 기다리지 않고 바로 알 수 있습니다.
  • 멀티 클라우드 비용 대시보드AWS, Azure, Google Cloud, Alibaba Cloud, Cloudflare 청구서를 서버 없이 하나의 원장에 모읍니다.
  • Cloudflare 비용 분할Cloudflare 청구서 뒤에 있는 Worker, R2 버킷, D1 데이터베이스, Durable Object를 확인합니다.
  • LLM API 비용 추적이미 받아 둔 내보내기 파일로 OpenAI, Anthropic, DeepSeek, Model Studio 모델별 토큰 비용을 확인합니다.

FAQ

자주 묻는 질문

CloudBridge는 무엇인가요?

무료 오픈소스 데스크톱 앱입니다. 각 서비스의 청구 API나 직접 내려받은 파일을 통해 클라우드와 AI 서비스의 청구서를 여러분의 컴퓨터에 있는 데이터베이스에 모읍니다. 무엇에 얼마를 쓰는지 보여 주고, 알림 규칙을 확인하며, 창을 닫은 뒤에도 메뉴 막대에서 계속 실행됩니다.

어떤 서비스를 지원하나요?

AWS(Cost Explorer 또는 S3에 있는 FOCUS Data Export), Azure(Cost Management), Alibaba Cloud와 Cloudflare는 청구 API로 연결합니다. Google Cloud는 BigQuery 청구 내보내기로, DeepSeek은 잔액 API로 연결하며, Alibaba Cloud, Volcengine, OpenAI, Anthropic, DeepSeek의 청구서 내보내기도 가져올 수 있습니다.

CloudBridge가 청구서를 어딘가로 보내나요?

아니요. 청구서는 서비스에서 여러분의 컴퓨터에 있는 DuckDB 파일로 바로 저장됩니다. CloudBridge 계정도, 동기화 서비스도, 텔레메트리도 없으며, 자격 증명은 시스템 키링에 보관됩니다.

CloudBridge를 쓰면 청구서 금액이 늘어나나요?

AWS에서만 늘어납니다. Cost Explorer는 요청마다, S3는 읽기마다 요금을 받습니다. CloudBridge는 새로 고침 주기(기본 24시간)마다 각 서비스에 최대 한 번만 요청하므로, AWS 계정당 하루에 Cost Explorer 요청 두 번 정도입니다. 이미 비용을 지불한 데이터를 다시 가져오지 않고, 변경되지 않은 S3 내보내기도 다시 내려받지 않습니다. 다른 API는 무료이며, 리소스를 만들거나 바꾸는 일은 없습니다.

비용 급증은 어떻게 감지하나요?

청구서를 일 단위로 읽기 때문에 급증은 다음 날 데이터에 나타납니다. 규칙은 최근 기준선을 넘는 지출, 예산, 낮은 잔액을 확인합니다. CloudBridge가 실행 중이면 창을 닫았더라도 각 계정을 하루 한 번 새로 고치고 알림마다 시스템 알림을 보냅니다. Cloudflare 청구서는 버킷, Worker, Durable Object 단위까지 나눌 수 있습니다.

어떤 운영체제에서 실행되나요?

Apple silicon용 macOS(서명 및 공증됨)와 64비트 Windows입니다. Linux와 Intel Mac은 소스에서 직접 빌드할 수 있습니다.

CloudBridge는 무료인가요?

네. MIT 라이선스로 무료 오픈소스이며, 전체 소스 코드가 GitHub에 있습니다. 서비스 API 요금은 별도입니다.

설치하지 않고 사용해 볼 수 있나요?

네. 브라우저 데모는 같은 앱을 WebAssembly로 컴파일해, 여러 서비스의 12개월치 샘플 청구서로 실행합니다.
