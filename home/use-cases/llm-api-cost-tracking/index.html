How it works

From a console export to cost per token

No API keys for OpenAI or Anthropic: the export their consoles give you is enough.

  1. Download the export

    OpenAI: Usage → Export. Anthropic: Usage or Cost → Export. DeepSeek: Usage → Download.

  2. Import it

    Add the account with a name and no credentials, then click Import on its row. Importing a month again replaces it.

  3. Read the Models page

    Each model's cost and change, its input, output and cache tokens, and what it costs per million tokens.

Keep watch

Know when model spend jumps

The cost growth anomaly rule flags a source and service whose daily spend runs above its trailing 7-day baseline for two days running. The balance floor rule warns before a prepaid balance like DeepSeek's runs out. CloudBridge posts both from the menu bar.

Cloud cost alerts

  • Model spend sits in the same ledger as AWS, Alibaba Cloud and Cloudflare, so one Overview covers it all.
  • Original currencies are kept beside the converted amount; missing exchange rates are reported, not assumed.
  • The ledger is a DuckDB file on your disk, with read-only SQL on the Query page.

FAQ

Questions people ask

Do I need to give CloudBridge my OpenAI or Anthropic API key?
No. OpenAI and Anthropic are import-only: add the account with a name and no credentials, then import the cost or usage export downloaded from the provider's console.
What if my export has tokens but no cost?
Token-only exports stay usage records. CloudBridge counts their tokens on the Models page but does not turn them into an estimated bill.
Which model providers does it read?
OpenAI and Anthropic exports, DeepSeek's balance API and usage download, Alibaba Cloud Model Studio through the Alibaba Cloud bill, and Volcengine Ark through the Volcengine bill export.
Can it warn me when model spend jumps?
Yes. The cost growth anomaly rule flags daily spend above its trailing 7-day baseline for consecutive days, and the balance floor rule warns when a prepaid balance such as DeepSeek's runs low.
