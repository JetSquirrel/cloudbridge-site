One format

Every bill in the same columns

Bills are stored with column names from the FinOps FOCUS standard, however they arrive. An Alibaba Cloud ECS instance and an AWS EC2 instance both count as Compute, and one SQL query covers every provider.

Query FOCUS and token data

  • Columns such as billed_cost, effective_cost, service_category and region_id mean the same thing for every source.
  • Totals are in one reporting currency; each charge keeps its original currency beside the converted amount.
  • Credits, refunds and one-off purchases are kept as what they are, not added to usage.
  • The ledger is a DuckDB file you can query with read-only SQL or export as FOCUS CSV.

Read the bill

Who spent it, and on what

The Overview shows the month to date, the forecast and the biggest movers across every source. Attribution maps spend to your business lines and breaks it down by tag, service, region or FOCUS service category.

Overview Attribution Reconciliation

  • Alert rules run on the same ledger: cost anomalies, account budgets, balance floors and untagged spend. Cloud cost alerts.
  • Model-provider bills sit beside the clouds, with cost per million tokens per model. LLM API cost tracking.
  • Reconciliation compares each provider's final invoice with the ledger, in the invoice's currency.

No server

A desktop app, not a platform to deploy

Most multi-cloud cost tools are a hosted service you send your bills to, or a server you deploy and maintain. CloudBridge is an app you install: the bills go from the provider to a file on your disk and nowhere else.

CloudBridge vs OptScale

  • No CloudBridge account, no sync service, no telemetry.
  • Read-only: no provider resource is created or changed.
  • Built for one person's view of the bills. A team that needs shared dashboards and roles wants a FinOps server instead.
  • Open source under MIT.

FAQ

Questions people ask

Do I need to deploy a server to see all my cloud costs together?

No. CloudBridge is a desktop app for macOS and Windows. It reads each provider with a read-only credential and keeps the bills in a DuckDB file on your disk. There is no server, database or account to set up.

Which clouds does CloudBridge read?

AWS, Microsoft Azure, Google Cloud, Alibaba Cloud and Cloudflare through their billing APIs or exports, and Volcengine through its bill export. Model-provider bills from OpenAI, Anthropic and DeepSeek land in the same ledger.

How does it add up bills in different currencies?

Totals are shown in one reporting currency. Each charge keeps its original currency beside the converted amount, and a charge with no exchange rate is reported as left out rather than assumed.

What is FOCUS, and why does it matter here?

FOCUS is the FinOps Foundation's open specification for billing data. CloudBridge names its columns after it, so an Alibaba Cloud ECS instance and an AWS EC2 instance both count as Compute and one SQL query covers every provider. The ledger can also be exported as FOCUS CSV.

Is CloudBridge a FinOps platform for a whole team?

No. It is a ledger on one person's computer, with no sync and no shared server. If an organization needs shared dashboards and roles, a FinOps server fits better; the CloudBridge vs OptScale post compares the two.

Does reading the bills cost anything?

Only where the provider charges for it: AWS Cost Explorer requests and S3 reads, and Google Cloud BigQuery queries past the monthly free tier. CloudBridge contacts each provider at most once per refresh interval, 24 hours by default.
