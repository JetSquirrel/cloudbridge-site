A fatura nomeia o serviço, não o recurso

Veja qual Worker, bucket ou Durable Object está por trás da sua fatura da Cloudflare

O CloudBridge lê seu uso faturável da Cloudflare por dia e divide cada cobrança entre seus buckets R2, Workers, bancos D1 e namespaces de Durable Object, em um registro no seu computador.

Baixar o CloudBridge Ler a documentação da Cloudflare

Gratuito e open source para macOS e Windows. Sem conta, sem sincronização, sem telemetria.

Como funciona

De um token de API ao custo por recurso

Um token somente leitura é suficiente. Ele fica no chaveiro do sistema.

  1. Crie um token

    Um token de API personalizado com Conta → Faturamento → Leitura. Adicione Conta → Análises da conta → Leitura para a divisão por recurso.

  2. Adicione a conta

    Informe o ID da conta e o token. O CloudBridge lê o uso faturável: gasto por serviço, por dia.

  3. Leia a divisão

    A cobrança de cada dia é dividida entre os recursos que usaram o medidor. O Insights lista a fatia de cada um e o uso dele neste período.

A divisão

O que é dividido, e entre o quê

A fatura da Cloudflare pode dizer “Operações R2 Classe B, 734 em 3 de outubro”. O CloudBridge pergunta à API GraphQL Analytics qual bucket as fez.

O que os números são

As partes somam a fatura

A divisão reparte o que a Cloudflare cobrou; ela não inventa um preço. As linhas são marcadas como estimativas, porque as análises são amostradas e a franquia gratuita pertence à conta, não a um recurso.

Insights Permissões do token

  • Um medidor que as análises não conseguem dividir, como KV ou Queues, mantém a linha inteira na conta.
  • O uso dentro da franquia gratuita também é registrado, com custo zero, porque é ali que um descontrole começa.
  • Sem a permissão de Análises da conta, a fatura ainda é lida; ela só não é dividida.
  • Somente contas pay-as-you-go. A API de uso faturável da Cloudflare está em alfa e não cobre Enterprise.

Pegue um descontrole

Saiba no primeiro dia em que um Worker entra em loop

Nada interrompe uma conta Cloudflare pay-as-you-go ao atingir um limite de gasto. Dê à conta um orçamento mensal e adicione uma regra de orçamento da conta baseada na previsão de fim de mês: o primeiro dia caro é projetado pelo mês, e o alerta dispara na primeira atualização que o lê.

Pegue um descontrole Alertas de custos na nuvem

  • Um caso real: o alarme de Durable Object de um projeto dormente cobrou US$ 10.811 antes de alguém saber. Leia o artigo.
  • Reduza o intervalo de atualização para 6 horas e mantenha o CloudBridge na barra de menus com Abrir ao iniciar ativado.
  • Quando o alerta dispara, o Insights mostra a fatia de cada Worker e de cada namespace, então o responsável se destaca.

Privacidade

Suas faturas ficam na sua máquina

O registro é um arquivo DuckDB no seu disco e o token está no chaveiro do sistema. O CloudBridge só lê da Cloudflare, e a fatura fica ao lado das suas faturas da AWS, Azure, Google Cloud e de provedores de modelos, nas mesmas colunas.

  • Sem conta CloudBridge, sem serviço de sincronização, sem telemetria.
  • Token somente leitura; nada na sua conta Cloudflare é criado ou alterado.
  • Open source sob MIT.

FAQ

Perguntas que as pessoas fazem

A fatura da Cloudflare mostra o custo de cada Worker ou bucket R2?

Não. A fatura para no serviço: ela diz quantas operações R2 Classe B ou linhas de Durable Object foram cobradas em um dia, não qual bucket ou namespace as usou. O CloudBridge lê o uso de cada recurso na API GraphQL Analytics da Cloudflare e divide a cobrança de cada dia por essas fatias.

Quão precisa é a divisão por recurso?

As partes somam o que a Cloudflare cobrou, e são marcadas como estimativas. As análises da Cloudflare são amostradas, e a franquia gratuita pertence à conta, não a um recurso específico.

Quais permissões o token de API precisa?

Conta, Faturamento, Leitura para a fatura, e Conta, Análises da conta, Leitura para a divisão. As duas são somente leitura. A varredura de recursos do Insights precisa de mais algumas permissões de Leitura e informa quais foram negadas.

Funciona com uma conta Cloudflare Enterprise?

Não. A API de uso faturável da Cloudflare cobre apenas contas pay-as-you-go (self-serve) e ainda é uma API alfa. O CloudBridge informa que uma conta Enterprise não é coberta.

O CloudBridge consegue parar um Worker ou Durable Object descontrolado?

Não. Ele só lê. Ele pode avisar você na primeira atualização que lê o dia caro, e o Insights mostra qual Worker ou namespace está por trás da cobrança, para você parar no painel da Cloudflare.
