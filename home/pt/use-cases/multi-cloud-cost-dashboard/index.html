AWS, Azure, Google Cloud, Alibaba Cloud e Cloudflare, lado a lado

Um registro para cada fatura de nuvem

O CloudBridge lê a fatura de cada nuvem por dia em um único banco de dados no seu computador, nas mesmas colunas e em uma moeda de relatório, para você ver o mês de todas elas sem rodar um servidor.

Baixar o CloudBridge Experimente a demo

Gratuito e open source para macOS e Windows. Sem conta, sem sincronização, sem telemetria.

Cada conexão usa uma credencial somente leitura limitada ao faturamento, guardada no chaveiro do sistema.

Um formato

Cada fatura nas mesmas colunas

As faturas são armazenadas com nomes de colunas do padrão FinOps FOCUS, não importa como chegam. Uma instância ECS da Alibaba Cloud e uma instância EC2 da AWS contam como Compute, e uma consulta SQL cobre todos os provedores.

Consulta FOCUS e dados de tokens

  • Colunas como billed_cost, effective_cost, service_category e region_id significam a mesma coisa para qualquer origem.
  • Os totais ficam em uma moeda de relatório; cada cobrança mantém a moeda original ao lado do valor convertido.
  • Créditos, reembolsos e compras avulsas são mantidos como são, sem serem somados ao uso.
  • O registro é um arquivo DuckDB que você pode consultar com SQL somente leitura ou exportar como CSV FOCUS.

Ler a fatura

Quem gastou, e com o quê

A Visão geral mostra o acumulado do mês, a previsão e as maiores variações de todas as origens. A Atribuição mapeia o gasto para suas linhas de negócio e o detalha por etiqueta, serviço, região ou categoria de serviço do FOCUS.

Visão geral Atribuição Conciliação

  • As regras de alerta rodam no mesmo registro: anomalias de custo, orçamentos de conta, pisos de saldo e gasto sem etiqueta. Alertas de custos na nuvem.
  • As faturas dos provedores de modelos ficam ao lado das nuvens, com custo por milhão de tokens por modelo. Acompanhamento de custos de API LLM.
  • A Conciliação compara a fatura final de cada provedor com o registro, na moeda da fatura.

Sem servidor

Um app de desktop, não uma plataforma para implantar

A maioria das ferramentas de custo multi-cloud é um serviço hospedado para o qual você envia suas faturas, ou um servidor que você implanta e mantém. O CloudBridge é um app que você instala: as faturas vão do provedor para um arquivo no seu disco e para nenhum outro lugar.

CloudBridge vs OptScale

  • Sem conta CloudBridge, sem serviço de sincronização, sem telemetria.
  • Somente leitura: nenhum recurso do provedor é criado ou alterado.
  • Feito para a visão de uma pessoa sobre as faturas. Uma equipe que precisa de dashboards compartilhados e papéis quer um servidor FinOps.
  • Open source sob MIT.

FAQ

Perguntas que as pessoas fazem

Preciso implantar um servidor para ver todos os custos de nuvem juntos?

Não. O CloudBridge é um app de desktop para macOS e Windows. Ele lê cada provedor com uma credencial somente leitura e mantém as faturas em um arquivo DuckDB no seu disco. Não há servidor, banco de dados nem conta para configurar.

Quais nuvens o CloudBridge lê?

AWS, Microsoft Azure, Google Cloud, Alibaba Cloud e Cloudflare pelas APIs ou exports de faturamento, e Volcengine pelo export de fatura. As faturas de provedores de modelos da OpenAI, Anthropic e DeepSeek entram no mesmo registro.

Como ele soma faturas em moedas diferentes?

Os totais aparecem em uma moeda de relatório. Cada cobrança mantém a moeda original ao lado do valor convertido, e uma cobrança sem taxa de câmbio é informada como excluída, não presumida.

O que é FOCUS, e por que isso importa aqui?

FOCUS é a especificação aberta da FinOps Foundation para dados de faturamento. O CloudBridge nomeia suas colunas a partir dela, então uma instância ECS da Alibaba Cloud e uma instância EC2 da AWS contam como Compute e uma consulta SQL cobre todos os provedores. O registro também pode ser exportado como CSV FOCUS.

O CloudBridge é uma plataforma FinOps para uma equipe inteira?

Não. É um registro no computador de uma pessoa, sem sincronização e sem servidor compartilhado. Se uma organização precisa de dashboards compartilhados e papéis, um servidor FinOps se encaixa melhor; o artigo CloudBridge vs OptScale compara os dois.

Ler as faturas custa alguma coisa?

Só onde o provedor cobra por isso: requisições ao AWS Cost Explorer e leituras no S3, e consultas do Google Cloud BigQuery acima da franquia mensal gratuita. O CloudBridge contata cada provedor no máximo uma vez por intervalo de atualização, 24 horas por padrão.
