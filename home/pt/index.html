Baixar

Veja todas as suas faturas de nuvem e de IA em um só lugar.

O CloudBridge é um app de desktop que reúne suas faturas da AWS, Azure, Google Cloud, Alibaba Cloud, Cloudflare, OpenAI, Anthropic e DeepSeek, mostra no que você está gastando e avisa quando os custos disparam. Tudo fica armazenado no seu computador.

Baixar para Mac Experimente a demo

Gratuito e open source. Sem cadastro, sem sincronização, sem telemetria. Também para Windows.

  • Dados armazenados localmente no DuckDB
  • Alertas na barra de menus
  • macOS e Windows
  • Open source (MIT)

Primeiros passos

Comece em três passos

Instale o app e siga estes passos. Você não precisa de servidor nem de conta.

  1. Adicione uma conta

    Informe uma chave de API somente leitura para provedores com API de faturamento, ou apenas um nome se você for importar arquivos. As chaves ficam salvas no chaveiro do sistema.

    OrigemCloudflareID da conta023e105f…c353Token de API••••••••••••Salvar

  2. Importe suas faturas

    O CloudBridge pode buscar as faturas direto no provedor, ou você pode importar um arquivo que já baixou. Nos dois casos o resultado tem o mesmo formato, com nomes de colunas do padrão FOCUS.

    • APIAWS 2026-10127 cobranças
    • APICloudflare 2026-1014 cobranças
    • ArquivoOpenAI 2026-09412 cobranças

  3. Confira os custos e crie alertas

    Detalhe os gastos por conta, serviço, modelo ou linha de negócio. Você recebe uma notificação quando um custo dispara.

Quer dar uma olhada antes? Uma Visão geral vazia oferece Carregar dados de demonstração, ou você pode experimentar a demo no navegador com uma fatura de exemplo.

No Windows, o instalador não tem assinatura de código, então o SmartScreen provavelmente vai exibir um aviso. Veja Primeiros passos para saber o que fazer.

Alertas

Os alertas continuam funcionando depois que você fecha a janela

Quando você fecha a janela, o CloudBridge continua na barra de menus e mostra os gastos do mês. Ele atualiza cada conta em um intervalo definido (uma vez por dia, por padrão), verifica suas regras de alerta e envia uma notificação quando uma delas é acionada. Ative Abrir ao iniciar para mantê-lo rodando depois de reiniciar.

Dados

Todas as faturas usam as mesmas colunas

As faturas são armazenadas no mesmo formato, não importa como chegam, com nomes de colunas do padrão FinOps FOCUS. Cada cobrança mantém a moeda original ao lado do valor convertido. Por exemplo, uma instância ECS da Alibaba Cloud e uma instância EC2 da AWS contam como Compute, e você pode consultar tudo com SQL.

Consulta Atribuição Modelos

SELECT provider, service_category,
       round(sum(billed_cost), 2) AS cost
FROM v_charge_normalized
WHERE billing_period = '2026-10'
GROUP BY ALL ORDER BY cost DESC;

Privacidade

Suas faturas ficam no seu computador

As faturas mostram o que você roda, para quem e quanto custa. O CloudBridge mantém tudo isso no seu computador.

  • As faturas ficam em um arquivo DuckDB no seu disco e não passam por nenhum outro servidor.
  • Sem conta, sem serviço de sincronização e sem telemetria.
  • As credenciais ficam no Keychain do macOS ou no Gerenciador de Credenciais do Windows.
  • Somente leitura: ele nunca cria nem altera nada no seu provedor.
  • Ele contata cada provedor no máximo uma vez por intervalo de atualização e nunca paga duas vezes pelos mesmos dados.
  • Open source sob a licença MIT, para você poder ler o código.

FAQ

Perguntas frequentes

O que é o CloudBridge?

Um app de desktop gratuito e open source que reúne as faturas dos seus provedores de nuvem e de IA em um banco de dados no seu computador, usando a API de faturamento de cada provedor ou um arquivo que você baixou. Ele mostra no que você está gastando, verifica suas regras de alerta e continua rodando na barra de menus depois que você fecha a janela.

Quais provedores ele suporta?

AWS (Cost Explorer, ou um FOCUS Data Export no S3), Azure (Cost Management), Alibaba Cloud e Cloudflare pelas APIs de faturamento; Google Cloud pelo export de faturamento do BigQuery; DeepSeek pela API de saldo; e exports de faturas da Alibaba Cloud, Volcengine, OpenAI, Anthropic e DeepSeek.

O CloudBridge envia minhas faturas para algum lugar?

Não. As faturas vão direto do provedor para um arquivo DuckDB no seu computador. Não existe conta CloudBridge, serviço de sincronização nem telemetria, e as credenciais ficam no chaveiro do sistema.

O CloudBridge vai aumentar a minha fatura?

Somente na AWS, onde o Cost Explorer cobra por requisição e o S3 cobra pela leitura. O CloudBridge contata cada provedor no máximo uma vez por intervalo de atualização (24 horas por padrão), o que dá cerca de duas requisições ao Cost Explorer por conta AWS por dia. Ele não repete uma busca já paga nem baixa de novo um export do S3 que não mudou. As outras APIs que ele chama são gratuitas, e ele nunca cria nem altera um recurso.

Como ele detecta picos de custo?

Ele lê as faturas por dia, então um pico aparece nos dados no dia seguinte. As regras verificam gastos acima da referência recente, orçamentos e saldos baixos. Enquanto o CloudBridge está rodando, mesmo com a janela fechada, ele atualiza cada conta uma vez por dia e envia uma notificação para cada alerta. As faturas da Cloudflare também podem ser divididas até o bucket, o Worker ou o Durable Object.

Em quais sistemas ele roda?

macOS em Apple silicon (assinado e notarizado) e Windows 64 bits. Linux e Macs Intel podem compilar a partir do código-fonte.

O CloudBridge é gratuito?

Sim. É gratuito e open source sob a licença MIT, com o código-fonte completo no GitHub. Eventuais taxas das APIs dos provedores são à parte.

Posso experimentar sem instalar?

Sim. A demo no navegador roda o mesmo app, compilado para WebAssembly, com uma fatura de exemplo que cobre doze meses e vários provedores.
