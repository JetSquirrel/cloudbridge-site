Die Rechnung nennt den Dienst, nicht die Ressource

Sehen Sie, welcher Worker, Bucket oder Durable Object hinter Ihrer Cloudflare-Rechnung steckt

CloudBridge liest Ihre abgerechnete Cloudflare-Nutzung tageweise und teilt die täglichen Kosten auf Ihre R2-Buckets, Workers, D1-Datenbanken und Durable-Object-Namespaces auf, in einem Journal auf Ihrem Computer.

CloudBridge herunterladen Cloudflare in der Dokumentation

Kostenlos und Open Source für macOS und Windows. Kein Konto, keine Synchronisierung, keine Telemetrie.

So funktioniert es

Vom API-Token zu Kosten pro Ressource

Ein schreibgeschütztes Token genügt. Es bleibt im Schlüsselbund Ihres Systems.

  1. Token erstellen

    Ein benutzerdefiniertes API-Token mit Account → Billing → Read. Für die Aufteilung pro Ressource zusätzlich Account → Account Analytics → Read.

  2. Konto hinzufügen

    Geben Sie Konto-ID und Token ein. CloudBridge liest die abgerechnete Nutzung: Ausgaben pro Dienst und Tag.

  3. Aufteilung lesen

    Die Tageskosten werden auf die Ressourcen verteilt, die den Zähler genutzt haben. Einblicke listet den Anteil jeder Ressource und ihre Nutzung in diesem Zeitraum.

Was die Zahlen bedeuten

Die Teile ergeben zusammen die Rechnung

Die Aufteilung verteilt, was Cloudflare abgerechnet hat; sie erfindet keinen Preis. Die Zeilen sind als Schätzungen gekennzeichnet, weil die Analytics mit Stichproben arbeiten und ein kostenloses Kontingent zum Konto gehört, nicht zu einer einzelnen Ressource.

Einblicke Token-Berechtigungen

  • Ein Zähler, den die Analytics nicht aufteilen können, etwa KV oder Queues, bleibt als ganze Zeile beim Konto.
  • Nutzung innerhalb des kostenlosen Kontingents wird ebenfalls erfasst, zu null Kosten, denn dort beginnt ein Ausreißer.
  • Ohne die Berechtigung Account Analytics wird die Rechnung trotzdem gelesen; sie wird nur nicht aufgeteilt.
  • Nur Pay-as-you-go-Konten. Cloudflares API für abgerechnete Nutzung ist im Alpha-Stadium und deckt Enterprise nicht ab.

Ausreißer erkennen

Erfahren Sie am ersten Tag, an dem ein Worker in einer Schleife läuft

Nichts stoppt ein Pay-as-you-go-Konto von Cloudflare bei einer Ausgabengrenze. Geben Sie dem Konto ein Monatsbudget und fügen Sie eine Regel für Kontobudgets auf Basis der Prognose zum Monatsende hinzu: Der erste teure Tag wird auf den Monat hochgerechnet, und die Warnung wird bei der ersten Aktualisierung ausgelöst, die ihn liest.

Ausreißer erkennen Warnungen zu Cloud-Kosten

  • Ein echter Fall: Der Durable-Object-Alarm eines ruhenden Projekts kostete 10.811 $, bevor jemand davon wusste. Zum Beitrag.
  • Verkürzen Sie das Aktualisierungsintervall auf 6 Stunden und lassen Sie CloudBridge mit Beim Anmelden öffnen in der Menüleiste.
  • Wenn die Warnung ausgelöst wird, zeigt Einblicke den Anteil jedes Workers und Namespace, sodass der Verursacher auffällt.

Datenschutz

Ihre Rechnungen bleiben auf Ihrem Rechner

Das Journal ist eine DuckDB-Datei auf Ihrer Festplatte, das Token liegt im Schlüsselbund des Betriebssystems. CloudBridge liest nur von Cloudflare, und die Rechnung steht neben Ihren Rechnungen von AWS, Azure, Google Cloud und Modellanbietern in denselben Spalten.

  • Kein CloudBridge-Konto, kein Synchronisierungsdienst, keine Telemetrie.
  • Schreibgeschütztes Token; in Ihrem Cloudflare-Konto wird nichts erstellt oder geändert.
  • Open Source unter MIT.

FAQ

Häufige Fragen

Zeigt Cloudflares Rechnung die Kosten jedes Workers oder R2-Buckets?

Nein. Die Rechnung endet beim Dienst: Sie nennt, wie viele R2-Class-B-Operationen oder Durable-Object-Zeilen an einem Tag abgerechnet wurden, nicht, welcher Bucket oder Namespace sie verursacht hat. CloudBridge liest die Nutzung jeder Ressource über Cloudflares GraphQL Analytics API und teilt die Tageskosten nach diesen Anteilen auf.

Wie genau ist die Aufteilung pro Ressource?

Die Teile ergeben zusammen, was Cloudflare abgerechnet hat, und sie sind als Schätzungen gekennzeichnet. Cloudflares Analytics arbeiten mit Stichproben, und ein kostenloses Kontingent gehört zum Konto, nicht zu einer einzelnen Ressource.

Welche Berechtigungen braucht das API-Token?

Account, Billing, Read für die Rechnung und Account, Account Analytics, Read für die Aufteilung. Beide sind schreibgeschützt. Der Ressourcen-Scan in Einblicke braucht einige weitere Read-Berechtigungen und meldet, welche verweigert wurden.

Funktioniert es mit einem Cloudflare-Enterprise-Konto?

Nein. Cloudflares API für abgerechnete Nutzung deckt nur Pay-as-you-go-Konten (Self-Serve) ab und ist noch eine Alpha-API. CloudBridge meldet ein Enterprise-Konto als nicht abgedeckt.

Kann CloudBridge einen aus dem Ruder laufenden Worker oder Durable Object stoppen?

Nein. Sie liest nur. Sie kann Sie bei der ersten Aktualisierung warnen, die den teuren Tag liest, und Einblicke zeigt, welcher Worker oder Namespace hinter der Berechnung steckt, sodass Sie ihn im Cloudflare-Dashboard stoppen können.
