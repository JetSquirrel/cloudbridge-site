Ein Journal für jede Cloud-Rechnung

CloudBridge liest die Rechnung jeder Cloud tageweise in eine Datenbank auf Ihrem Computer, in denselben Spalten und einer Berichtswährung, sodass Sie den Monat über alle hinweg sehen, ohne einen Server zu betreiben.

Kostenlos und Open Source für macOS und Windows. Kein Konto, keine Synchronisierung, keine Telemetrie.

Wie sich jede Cloud verbindet

Ein Format

Jede Rechnung in denselben Spalten

Rechnungen werden mit Spaltennamen aus dem FinOps-Standard FOCUS gespeichert, egal wie sie eintreffen. Eine Alibaba-Cloud-ECS-Instanz und eine AWS-EC2-Instanz zählen beide als Compute, und eine SQL-Abfrage deckt jeden Anbieter ab.

Abfrage FOCUS und Token-Daten

  • Spalten wie billed_cost, effective_cost, service_category und region_id bedeuten für jede Quelle dasselbe.
  • Summen stehen in einer Berichtswährung; jede Buchung behält ihre Originalwährung neben dem umgerechneten Betrag.
  • Gutschriften, Erstattungen und Einmalkäufe bleiben, was sie sind, und werden nicht zur Nutzung addiert.
  • Das Journal ist eine DuckDB-Datei, die Sie mit schreibgeschütztem SQL abfragen oder als FOCUS-CSV exportieren können.

Die Rechnung lesen

Wer was ausgegeben hat

Die Übersicht zeigt den laufenden Monat, die Prognose und die größten Veränderungen über alle Quellen. Die Zuordnung ordnet Ausgaben Ihren Geschäftsbereichen zu und schlüsselt sie nach Tag, Dienst, Region oder FOCUS-Dienstkategorie auf.

Übersicht Zuordnung Abgleich

  • Warnregeln laufen auf demselben Journal: Kostenanomalien, Kontobudgets, Mindestguthaben und nicht zugeordnete Ausgaben. Warnungen zu Cloud-Kosten.
  • Rechnungen von Modellanbietern stehen neben den Clouds, mit Kosten pro Million Tokens je Modell. LLM-API-Kosten verfolgen.
  • Der Abgleich vergleicht die Schlussrechnung jedes Anbieters mit dem Journal, in der Währung der Rechnung.

Ohne Server

Eine Desktop-App, keine Plattform zum Bereitstellen

Die meisten Multi-Cloud-Kostentools sind ein gehosteter Dienst, an den Sie Ihre Rechnungen schicken, oder ein Server, den Sie bereitstellen und warten. CloudBridge ist eine App, die Sie installieren: Die Rechnungen gehen vom Anbieter in eine Datei auf Ihrer Festplatte und nirgendwohin sonst.

CloudBridge vs OptScale

  • Kein CloudBridge-Konto, kein Synchronisierungsdienst, keine Telemetrie.
  • Schreibgeschützt: keine Ressource beim Anbieter wird erstellt oder geändert.
  • Gebaut für die Sicht einer Person auf die Rechnungen. Ein Team, das gemeinsame Dashboards und Rollen braucht, möchte eher einen FinOps-Server.
  • Open Source unter MIT.

FAQ

Häufige Fragen

Muss ich einen Server bereitstellen, um alle Cloud-Kosten zusammen zu sehen?

Nein. CloudBridge ist eine Desktop-App für macOS und Windows. Sie liest jeden Anbieter mit schreibgeschützten Zugangsdaten und bewahrt die Rechnungen in einer DuckDB-Datei auf Ihrer Festplatte auf. Es gibt keinen Server, keine Datenbank und kein Konto einzurichten.

Welche Clouds liest CloudBridge?

AWS, Microsoft Azure, Google Cloud, Alibaba Cloud und Cloudflare über ihre Abrechnungs-APIs oder Exporte sowie Volcengine über den Rechnungsexport. Rechnungen von Modellanbietern wie OpenAI, Anthropic und DeepSeek landen im selben Journal.

Wie summiert CloudBridge Rechnungen in verschiedenen Währungen?

Summen werden in einer Berichtswährung angezeigt. Jede Buchung behält ihre Originalwährung neben dem umgerechneten Betrag, und eine Buchung ohne Wechselkurs wird als nicht berücksichtigt gemeldet statt geschätzt.

Was ist FOCUS, und warum ist es hier wichtig?

FOCUS ist die offene Spezifikation der FinOps Foundation für Abrechnungsdaten. CloudBridge benennt seine Spalten danach, sodass eine Alibaba-Cloud-ECS-Instanz und eine AWS-EC2-Instanz beide als Compute zählen und eine SQL-Abfrage jeden Anbieter abdeckt. Das Journal lässt sich zudem als FOCUS-CSV exportieren.

Ist CloudBridge eine FinOps-Plattform für ein ganzes Team?

Nein. Es ist ein Journal auf dem Computer einer Person, ohne Synchronisierung und ohne gemeinsamen Server. Wenn eine Organisation gemeinsame Dashboards und Rollen braucht, passt ein FinOps-Server besser; der Beitrag CloudBridge vs OptScale vergleicht die beiden.

Kostet das Lesen der Rechnungen etwas?

Nur wo der Anbieter es berechnet: Anfragen an AWS Cost Explorer und S3-Lesezugriffe sowie Google-Cloud-BigQuery-Abfragen über das monatliche kostenlose Kontingent hinaus. CloudBridge kontaktiert jeden Anbieter höchstens einmal pro Aktualisierungsintervall, standardmäßig alle 24 Stunden.
