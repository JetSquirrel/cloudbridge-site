Herunterladen

Alle Ihre Cloud- und KI-Rechnungen an einem Ort.

CloudBridge ist eine Desktop-App, die Ihre Rechnungen von AWS, Azure, Google Cloud, Alibaba Cloud, Cloudflare, OpenAI, Anthropic und DeepSeek sammelt, zeigt, wofür Sie Geld ausgeben, und Sie warnt, wenn die Kosten steigen. Alles wird auf Ihrem Computer gespeichert.

Für Mac herunterladen Demo ausprobieren

Kostenlos und Open Source. Ohne Registrierung, ohne Synchronisierung, ohne Telemetrie. Auch für Windows.

  • Daten lokal in DuckDB gespeichert
  • Warnungen aus der Menüleiste
  • macOS und Windows
  • Open Source (MIT)

Installieren Sie die App und folgen Sie diesen Schritten. Sie brauchen weder einen Server noch ein Konto.

  1. Ein Konto hinzufügen

    Geben Sie einen schreibgeschützten API-Schlüssel für Anbieter mit Abrechnungs-API ein, oder nur einen Namen, wenn Sie Dateien importieren möchten. Schlüssel werden im Schlüsselbund Ihres Systems gespeichert.

  2. Rechnungen importieren

    CloudBridge kann Rechnungen beim Anbieter abrufen, oder Sie importieren eine heruntergeladene Datei. Beides landet im selben Format, mit Spaltennamen aus dem FOCUS-Standard.

  3. Kosten prüfen und Warnungen einrichten

Unter Windows ist der Installer nicht code-signiert, daher zeigt SmartScreen wahrscheinlich einen Hinweis. Was zu tun ist, steht unter Erste Schritte.

Warnungen

Warnungen bleiben aktiv, wenn Sie das Fenster schließen

Wenn Sie das Fenster schließen, bleibt CloudBridge in der Menüleiste und zeigt die Ausgaben dieses Monats. Sie aktualisiert jedes Konto nach einem Zeitplan (standardmäßig einmal täglich), prüft Ihre Warnregeln und sendet eine Benachrichtigung, wenn eine ausgelöst wird. Aktivieren Sie Beim Anmelden öffnen, damit sie nach einem Neustart weiterläuft.

Kosten nach Ressource

Sehen Sie, was jeder Bucket, Worker und Durable Object kostet

Cloudflares Rechnung nennt vielleicht „R2 Class B operations, 734 am 3. Oktober", ohne den Bucket zu nennen. CloudBridge ruft die tägliche Nutzung jeder Ressource aus Cloudflares Analytics ab und verteilt die Kosten darauf, sodass Sie sehen, welche verantwortlich ist. Sie erfasst auch Nutzung innerhalb des kostenlosen Kontingents, denn ein Kostenproblem kann dort beginnen, bevor Ihnen etwas berechnet wird.

Daten

Alle Rechnungen nutzen dieselben Spalten

Rechnungen werden unabhängig von ihrem Weg im selben Format gespeichert, mit Spaltennamen aus dem FinOps-Standard FOCUS. Jede Buchung behält ihre Originalwährung neben dem umgerechneten Betrag. Eine Alibaba-Cloud-ECS-Instanz und eine AWS-EC2-Instanz zählen beispielsweise beide als Compute, und Sie können alles mit SQL abfragen.

Abfrage Zuordnung Modelle

SELECT provider, service_category,
       round(sum(billed_cost), 2) AS cost
FROM v_charge_normalized
WHERE billing_period = '2026-10'
GROUP BY ALL ORDER BY cost DESC;

Datenschutz

Ihre Rechnungen bleiben auf Ihrem Computer

Rechnungen zeigen, was Sie betreiben, für wen und zu welchem Preis. CloudBridge behält all das auf Ihrem Computer.

  • Rechnungen liegen in einer DuckDB-Datei auf Ihrer Festplatte und laufen über keinen anderen Server.
  • Kein Konto, kein Synchronisierungsdienst und keine Telemetrie.
  • Zugangsdaten liegen im macOS-Schlüsselbund oder im Windows-Anmeldeinformationsmanager.
  • Schreibgeschützt: Beim Anbieter wird nichts erstellt oder geändert.
  • Jeder Anbieter wird höchstens einmal pro Aktualisierungsintervall kontaktiert, und dieselben Daten werden nicht zweimal bezahlt.
  • Open Source unter der MIT-Lizenz, Sie können den Code also lesen.

FAQ

Häufige Fragen

Was ist CloudBridge?

Eine kostenlose Open-Source-Desktop-App, die Ihre Rechnungen von Cloud- und KI-Anbietern in einer Datenbank auf Ihrem Computer sammelt, über die Abrechnungs-API des jeweiligen Anbieters oder eine von Ihnen heruntergeladene Datei. Sie zeigt, wofür Sie Geld ausgeben, prüft Ihre Warnregeln und läuft nach dem Schließen des Fensters in der Menüleiste weiter.

Welche Anbieter werden unterstützt?

AWS (Cost Explorer oder ein FOCUS Data Export in S3), Azure (Cost Management), Alibaba Cloud und Cloudflare über ihre Abrechnungs-APIs; Google Cloud über den BigQuery-Abrechnungsexport; DeepSeek über die Guthaben-API; außerdem Rechnungsexporte von Alibaba Cloud, Volcengine, OpenAI, Anthropic und DeepSeek.

Sendet CloudBridge meine Rechnungen irgendwohin?

Nein. Die Rechnungen gehen direkt vom Anbieter in eine DuckDB-Datei auf Ihrem Computer. Es gibt kein CloudBridge-Konto, keinen Synchronisierungsdienst und keine Telemetrie, und Zugangsdaten liegen im Schlüsselbund Ihres Systems.

Erhöht CloudBridge meine Rechnung?

Nur bei AWS, wo Cost Explorer pro Anfrage und S3 für Lesezugriffe berechnet. CloudBridge kontaktiert jeden Anbieter höchstens einmal pro Aktualisierungsintervall (standardmäßig 24 Stunden), das sind etwa zwei Cost-Explorer-Anfragen pro AWS-Konto und Tag. Einen bereits bezahlten Abruf wiederholt sie nicht und lädt einen unveränderten S3-Export nicht erneut. Die übrigen abgefragten APIs sind kostenlos, und sie erstellt oder ändert niemals eine Ressource.

Wie erkennt CloudBridge Kostenausreißer?

Sie liest Rechnungen tageweise, ein Ausreißer erscheint also am nächsten Tag in den Daten. Regeln prüfen Ausgaben über dem jüngsten Durchschnittswert, Budgets und niedrige Guthaben. Während CloudBridge läuft, auch bei geschlossenem Fenster, aktualisiert sie jedes Konto einmal täglich und sendet für jede Warnung eine Benachrichtigung. Cloudflare-Rechnungen lassen sich zudem bis auf Bucket, Worker oder Durable Object aufschlüsseln.

Auf welchen Systemen läuft CloudBridge?

macOS auf Apple Silicon (signiert und notarisiert) und 64-Bit-Windows. Linux und Intel-Macs können sie aus dem Quellcode bauen.

Ist CloudBridge kostenlos?

Ja. Sie ist kostenlos und Open Source unter der MIT-Lizenz, der vollständige Quellcode liegt auf GitHub. Eventuelle API-Gebühren der Anbieter kommen hinzu.

Kann ich CloudBridge ohne Installation testen?

Ja. Die Browser-Demo führt dieselbe App, zu WebAssembly kompiliert, mit einer Beispielrechnung über zwölf Monate und mehrere Anbieter aus.
