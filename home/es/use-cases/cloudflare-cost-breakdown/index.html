La factura nombra el servicio, no el recurso

Descubre qué Worker, bucket o Durable Object está detrás de tu factura de Cloudflare

CloudBridge lee cada día tu uso facturable de Cloudflare y divide cada cargo entre tus buckets de R2, Workers, bases de datos D1 y espacios de nombres de Durable Objects, en un registro en tu equipo.

Descargar CloudBridge Leer la documentación de Cloudflare

Gratis y de código abierto para macOS y Windows. Sin cuenta, sin sincronización y sin telemetría.

Cómo funciona

De un token de API al costo por recurso

Basta con un token de solo lectura. Se guarda en el llavero de tu sistema.

  1. Crea un token

    Un token de API personalizado con Cuenta → Facturación → Lectura. Añade Cuenta → Analíticas de cuenta → Lectura para el desglose por recurso.

  2. Añade la cuenta

    Introduce el ID de cuenta y el token. CloudBridge lee el uso facturable: gasto por servicio y por día.

  3. Lee el desglose

    El cargo de cada día se divide entre los recursos que usaron el medidor. Análisis muestra la parte de cada uno y su uso en este periodo.

El desglose

Qué se divide y entre qué

La factura de Cloudflare puede decir «operaciones de clase B de R2, 734 el 3 de octubre». CloudBridge pregunta a la API GraphQL Analytics qué bucket las hizo.

En la facturaSe divide entrePor
Operaciones de clase A y B de R2, almacenamientoBuckets de R2Uso de ese medidor por cada bucket
Solicitudes y CPU de WorkersWorkersSolicitudes de cada Worker

Qué significan los números

Las partes suman la factura

El desglose divide lo que facturó Cloudflare; no inventa un precio. Las filas se marcan como estimaciones, porque las analíticas son muestreadas y un límite gratuito pertenece a la cuenta, no a un recurso.

Análisis Permisos del token

  • Un medidor que las analíticas no pueden dividir, como KV o Queues, mantiene su fila entera en la cuenta.
  • El uso dentro del límite gratuito también se registra, con costo cero, porque es donde empieza un gasto descontrolado.
  • Sin el permiso de Analíticas de cuenta, la factura se sigue leyendo; simplemente no se divide.
  • Solo cuentas de pago por uso. La API de uso facturable de Cloudflare está en alfa y no cubre Enterprise.

Detén un gasto descontrolado

Entérate el primer día en que un Worker empieza a repetir en bucle

Nada detiene una cuenta de Cloudflare de pago por uso al alcanzar un límite de gasto. Asigna a la cuenta un presupuesto mensual y añade una regla de presupuesto de cuenta basada en la previsión de fin de mes: el primer día caro se proyecta sobre el mes y la alerta salta en la primera actualización que lo lee.

Detener un gasto descontrolado Alertas de costos de nube

  • Un caso real: la alarma de Durable Object de un proyecto inactivo facturó 10.811 dólares antes de que nadie lo supiera. Leer el artículo.
  • Acorta el intervalo de actualización a 6 horas y mantén CloudBridge en la barra de menús con Abrir al iniciar sesión activado.
  • Cuando salta la alerta, Análisis muestra la parte de cada Worker y cada espacio de nombres, para que destaque el responsable.

Privacidad

Tus facturas se quedan en tu equipo

El registro es un archivo DuckDB en tu disco y el token está en el llavero del sistema. CloudBridge solo lee de Cloudflare, y la factura se coloca junto a tus facturas de AWS, Azure, Google Cloud y proveedores de modelos, con las mismas columnas.

  • Sin cuenta de CloudBridge, sin servicio de sincronización y sin telemetría.
  • Token de solo lectura; no se crea ni se modifica nada en tu cuenta de Cloudflare.
  • Código abierto con licencia MIT.

FAQ

Preguntas que hace la gente

¿La factura de Cloudflare muestra el costo de cada Worker o bucket de R2?

No. La factura se queda en el servicio: dice cuántas operaciones de clase B de R2 o filas de Durable Object se facturaron en un día, no qué bucket o espacio de nombres las usó. CloudBridge lee el uso de cada recurso desde la API GraphQL Analytics de Cloudflare y reparte el cargo de cada día según esas proporciones.

¿Qué precisión tiene el desglose por recurso?

Las partes suman lo que facturó Cloudflare y se marcan como estimaciones. Las analíticas de Cloudflare son muestreadas, y un límite gratuito pertenece a la cuenta, no a un recurso concreto.

¿Qué permisos necesita el token de API?

Cuenta, Facturación, Lectura para la factura, y Cuenta, Analíticas de cuenta, Lectura para el desglose. Ambos son de solo lectura. El escaneo de recursos de Análisis necesita algunos permisos de Lectura más e indica cuáles se le denegaron.

¿Funciona con una cuenta Cloudflare Enterprise?

No. La API de uso facturable de Cloudflare solo cubre cuentas de pago por uso (autoservicio) y sigue siendo una API alfa. CloudBridge indica que una cuenta Enterprise no está cubierta.

¿Puede CloudBridge detener un Worker o un Durable Object desbocado?

No. Solo lee. Puede avisarte en la primera actualización que lea el día caro, y Análisis muestra qué Worker o espacio de nombres está detrás del cargo, para que lo detengas en el panel de Cloudflare.
