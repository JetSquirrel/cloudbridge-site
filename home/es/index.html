Descargar

Ve todas tus facturas de nube e IA en un solo lugar.

CloudBridge es una app de escritorio que reúne tus facturas de AWS, Azure, Google Cloud, Alibaba Cloud, Cloudflare, OpenAI, Anthropic y DeepSeek, te muestra en qué estás gastando y te avisa cuando los costos se disparan. Todo se guarda en tu equipo.

Descargar para Mac Probar la demo

Gratis y de código abierto. Sin registro, sin sincronización y sin telemetría. También para Windows.

  • Datos guardados localmente en DuckDB
  • Alertas desde la barra de menús
  • macOS y Windows
  • Código abierto (MIT)

Primeros pasos

Empieza en tres pasos

Instala la app y sigue estos pasos. No necesitas un servidor ni una cuenta.

  1. Añade una cuenta

    Introduce una clave de API de solo lectura para los proveedores que tienen API de facturación, o solo un nombre si vas a importar archivos. Las claves se guardan en el llavero de tu sistema.

    OrigenCloudflareID de cuenta023e105f…c353Token de API••••••••••••Guardar

  2. Importa tus facturas

    CloudBridge puede obtener las facturas del proveedor, o puedes importar un archivo que hayas descargado. Todo acaba en el mismo formato, con nombres de columna del estándar FOCUS.

    • APIAWS 2026-10127 cargos
    • APICloudflare 2026-1014 cargos
    • ArchivoOpenAI 2026-09412 cargos

  3. Revisa los costos y configura alertas

    Desglosa el gasto por cuenta, servicio, modelo o línea de negocio. Recibirás una notificación cuando un costo se dispare.

¿Quieres echar un vistazo primero? Un Resumen vacío ofrece Cargar datos de demo, o puedes probar la demo en el navegador con una factura de ejemplo.

En Windows, el instalador no tiene firma de código, así que SmartScreen probablemente muestre un aviso. Consulta Primeros pasos para saber qué hacer.

Alertas

Las alertas siguen funcionando cuando cierras la ventana

Cuando cierras la ventana, CloudBridge permanece en la barra de menús y muestra el gasto de este mes. Actualiza cada cuenta según una programación (una vez al día de forma predeterminada), comprueba tus reglas de alerta y envía una notificación si se activa alguna. Activa Abrir al iniciar sesión para que siga funcionando después de reiniciar.

Costo por recurso

Mira cuánto cuesta cada bucket, Worker y Durable Object

La factura de Cloudflare puede decir «operaciones de clase B de R2, 734 el 3 de octubre» sin nombrar el bucket. CloudBridge obtiene el uso diario de cada recurso desde las analíticas de Cloudflare y reparte el costo entre ellos, para que veas cuál es el responsable. También registra el uso dentro del límite gratuito, porque un problema de costos puede empezar ahí antes de que te cobren nada.

Datos

Todas las facturas usan las mismas columnas

Las facturas se guardan en el mismo formato, sin importar cómo lleguen, con nombres de columna del estándar FOCUS de FinOps. Cada cargo conserva su moneda original junto al importe convertido. Por ejemplo, una instancia ECS de Alibaba Cloud y una instancia EC2 de AWS cuentan como Compute, y puedes consultarlo todo con SQL.

Consulta Atribución Modelos

SELECT provider, service_category,
       round(sum(billed_cost), 2) AS cost
FROM v_charge_normalized
WHERE billing_period = '2026-10'
GROUP BY ALL ORDER BY cost DESC;

Privacidad

Tus facturas se quedan en tu equipo

Las facturas muestran qué ejecutas, para quién es y cuánto cuesta. CloudBridge mantiene todo eso en tu equipo.

  • Las facturas se guardan en un archivo DuckDB en tu disco y no pasan por ningún otro servidor.
  • Sin cuenta, sin servicio de sincronización y sin telemetría.
  • Las credenciales se guardan en el Llavero de macOS o en el Administrador de credenciales de Windows.
  • Solo lectura: nunca crea ni modifica nada en tu proveedor.
  • Contacta con cada proveedor como máximo una vez por intervalo de actualización y no paga dos veces por los mismos datos.
  • Código abierto con licencia MIT, para que puedas leer el código.

FAQ

Preguntas frecuentes

¿Qué es CloudBridge?

Una app de escritorio gratis y de código abierto que reúne tus facturas de proveedores de nube e IA en una base de datos en tu equipo, usando la API de facturación de cada proveedor o un archivo que hayas descargado. Te muestra en qué estás gastando, comprueba tus reglas de alerta y sigue funcionando en la barra de menús después de cerrar la ventana.

¿Qué proveedores admite?

AWS (Cost Explorer o una exportación de datos FOCUS en S3), Azure (Cost Management), Alibaba Cloud y Cloudflare a través de sus API de facturación; Google Cloud a través de su exportación de facturación de BigQuery; DeepSeek a través de su API de saldo; y exportaciones de facturas de Alibaba Cloud, Volcengine, OpenAI, Anthropic y DeepSeek.

¿CloudBridge envía mis facturas a algún sitio?

No. Las facturas van directamente del proveedor a un archivo DuckDB en tu equipo. No hay cuenta de CloudBridge, ni servicio de sincronización, ni telemetría, y las credenciales se guardan en el llavero de tu sistema.

¿CloudBridge va a aumentar mi factura?

Solo en AWS, donde Cost Explorer cobra por solicitud y S3 cobra por las lecturas. CloudBridge contacta con cada proveedor como máximo una vez por intervalo de actualización (24 horas de forma predeterminada), lo que supone unas dos solicitudes de Cost Explorer por cuenta de AWS al día. No repite una consulta que ya ha pagado ni vuelve a descargar una exportación de S3 sin cambios. Las demás API que utiliza son gratuitas y nunca crea ni modifica un recurso.

¿Cómo detecta los picos de costos?

Lee las facturas por día, así que un pico aparece en los datos al día siguiente. Las reglas comprueban el gasto por encima de su línea base reciente, los presupuestos y los saldos bajos. Mientras CloudBridge se está ejecutando, incluso con la ventana cerrada, actualiza cada cuenta una vez al día y envía una notificación por cada alerta. Las facturas de Cloudflare también se pueden dividir hasta el bucket, el Worker o el Durable Object.

¿En qué sistemas funciona?

macOS en Apple silicon (firmado y notarizado) y Windows de 64 bits. Linux y los Mac con Intel pueden compilarlo desde el código fuente.

¿CloudBridge es gratis?

Sí. Es gratis y de código abierto con licencia MIT, con el código fuente completo en GitHub. Las posibles tarifas de las API de los proveedores van aparte.

¿Puedo probarlo sin instalarlo?

Sí. La demo en el navegador ejecuta la misma app, compilada a WebAssembly, con una factura de ejemplo que cubre doce meses y varios proveedores.
