账单只说是哪个服务，不说是哪个资源

看清 Cloudflare 账单背后是哪个 Worker、bucket 或 Durable Object

CloudBridge 按天读取 Cloudflare 的计费用量，把每一笔费用拆到具体的 R2 bucket、Worker、D1 数据库和 Durable Object namespace，记在你电脑上的一本账里。

免费开源，支持 macOS 和 Windows。无需注册，不同步，不上报任何数据。

怎么用

从一个 API token 到每个资源的费用

只需要一个只读 token，它保存在系统钥匙串里。

  1. 创建 token

    创建一个自定义 API token，授予 Account → Billing → Read。要按资源拆分，再加上 Account → Account Analytics → Read。

  2. 添加账号

    填入 Account ID 和 token。CloudBridge 读取计费用量：按服务、按天的花费。

  3. 查看拆分结果

    每天的费用按用量占比分给用到该计量项的资源。资源洞察会列出每个资源的份额和本期用量。

拆分

哪些费用会拆，拆给谁

Cloudflare 的账单可能只写着“R2 Class B operations，10 月 3 日 734 次”。CloudBridge 会去 GraphQL Analytics API 查这些操作来自哪个 bucket。

账单上的项目拆分到依据
R2 Class A、Class B 操作和存储R2 bucket每个 bucket 在该计量项上的用量
Workers 请求数和 CPUWorker每个 Worker 的请求数
D1 读写行数和存储D1 数据库每个数据库在该计量项上的用量
Durable Objects 请求、时长、读写行数和存储Durable Object namespace每个 namespace 在该计量项上的用量

这些数字是什么

拆出来的各部分，加起来等于账单

拆分只是把 Cloudflare 已经计费的金额分下去，不会自己定价。拆出来的行都标记为估算值，因为分析数据是抽样的，而免费额度属于整个账号，不属于某一个资源。

资源洞察 token 权限

  • 分析数据拆不了的计量项，比如 KV 和 Queues，整行保留在账号上。
  • 免费额度内的用量也会记下来，费用记为零，因为失控往往从那里开始。
  • 没有 Account Analytics 权限也能读账单，只是不做拆分。
  • 只支持按量付费账号。Cloudflare 的计费用量 API 还是 alpha 版本，不覆盖企业版。

发现失控

Worker 开始死循环的第一天就知道

按量付费的 Cloudflare 账号没有消费上限。给账号设一个月度预算，再加一条基于月底预测的账号预算规则：第一天的高额花费会被外推到整个月，读到这一天的第一次刷新就会触发告警。

发现失控的用量 云费用异常告警

  • 真实案例：一个没人用的项目里，Durable Object 的 alarm 在没人察觉的情况下跑出了 10,811 美元的账单。阅读文章。
  • 把刷新间隔缩短到 6 小时，让 CloudBridge 留在状态栏，并打开开机启动。
  • 告警触发后，资源洞察会显示每个 Worker 和 namespace 的份额，一眼就能看出是谁。

隐私

你的账单只留在你的电脑上

账本是你磁盘上的一个 DuckDB 文件，token 存在系统钥匙串里。CloudBridge 对 Cloudflare 只读不写，这份账单和 AWS、Azure、Google Cloud 以及各家模型平台的账单用的是同一套列。

  • 没有 CloudBridge 账号，没有同步服务，不上报任何数据。
  • 只读 token，不会创建或修改你 Cloudflare 账号里的任何东西。
  • 基于 MIT 许可开源。

常见问题

大家常问的问题

Cloudflare 的账单能看到每个 Worker 或 R2 bucket 的费用吗？

不能。账单只到服务这一级：它告诉你某一天计费了多少次 R2 Class B 操作、多少行 Durable Object 读写，但不说是哪个 bucket 或 namespace 用的。CloudBridge 通过 Cloudflare 的 GraphQL Analytics API 读取每个资源的用量，再按占比拆分每一天的费用。

按资源拆分的结果有多准？

各部分加起来等于 Cloudflare 实际计费的金额，并且标记为估算值。原因是 Cloudflare 的分析数据是抽样的，而免费额度属于整个账号，不属于某一个资源。

API token 需要哪些权限？

读账单需要 Account → Billing → Read，按资源拆分需要 Account → Account Analytics → Read，两者都是只读权限。资源洞察的扫描还需要另外几项 Read 权限，缺了哪项它会明确告诉你。

企业版（Enterprise）账号能用吗？

不能。Cloudflare 的计费用量 API 只覆盖按量付费（自助）账号，而且还是 alpha 版本。企业版账号在 CloudBridge 里会提示不在覆盖范围内。

CloudBridge 能自动停掉失控的 Worker 或 Durable Object 吗？

不能，它只读不写。它能做的是在读到高额花费那一天的第一次刷新时发出告警，并在资源洞察里显示是哪个 Worker 或 namespace 在花钱，方便你去 Cloudflare 控制台把它停掉。
