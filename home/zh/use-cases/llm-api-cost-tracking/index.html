怎么用

从控制台导出文件，到每个 token 的成本

不需要 OpenAI 或 Anthropic 的 API key，控制台给的导出文件就够了。

  1. 下载导出文件

    OpenAI 在 Usage 页导出，Anthropic 在 Usage 或 Cost 页导出，DeepSeek 在用量信息页导出。

  2. 导入

    添加账号时只填名字、不填凭据，然后在这一行点导入。同一个月再导入一次会整月替换，不会重复计费。

  3. 打开模型页

    每个模型的花费和变化，输入、输出和缓存 token，以及每百万 token 的成本。

持续盯着

模型花费一突增就知道

费用增长异常规则会在某个数据源和服务的每日花费连续两天超过它过去 7 天的基线时告警；余额下限规则会在 DeepSeek 这样的预付费余额快用完之前提醒你。两种告警都从状态栏发出。

云费用异常告警

  • 模型花费和 AWS、阿里云、Cloudflare 的账单记在同一本账里，一个总览页全看到。
  • 保留每笔费用的原始币种，缺少汇率时会明确标出，而不是当成一比一。
  • 账本是你磁盘上的一个 DuckDB 文件，查询页可以直接写只读 SQL。

常见问题

大家常问的问题

需要把 OpenAI 或 Anthropic 的 API key 交给 CloudBridge 吗？
不需要。OpenAI 和 Anthropic 目前只支持导入：添加账号时只填名字、不填凭据，然后导入从控制台下载的费用或用量文件。
导出文件里只有 token 没有金额怎么办？
只有 token 的用量文件会作为用量记录保存。CloudBridge 会在模型页统计它的 token，但不会按标价把它换算成估算账单。
支持哪些模型平台？
OpenAI 和 Anthropic 的导出文件，DeepSeek 的余额 API 和用量下载，阿里云账单里的百炼，以及火山引擎账单导出里的火山方舟。
模型花费突增时能提醒我吗？
能。费用增长异常规则会在每日花费连续几天超过过去 7 天的基线时告警；余额下限规则会在 DeepSeek 这样的预付费余额快用完时提醒。
