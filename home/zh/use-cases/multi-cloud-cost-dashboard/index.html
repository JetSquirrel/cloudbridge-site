同一种格式

所有账单都用同一套列

不管账单从哪来，都按 FinOps FOCUS 标准的列名保存。阿里云的 ECS 和 AWS 的 EC2 都归为 Compute，一条 SQL 就能查所有云。

SQL 查询 FOCUS 与 token 数据

  • billed_cost、effective_cost、service_category、region_id 这些列，对每个来源含义都一样。
  • 合计按一种报表货币显示；每笔费用在换算后的金额旁边保留原始币种。
  • 抵扣、退款和一次性购买按原样记录，不会混进用量里。
  • 账本是一个 DuckDB 文件，可以用只读 SQL 查询，也可以导出为 FOCUS CSV。

不用服务器

装上就能用的桌面应用，不是要部署的平台

多云成本工具大多是要你把账单交出去的托管服务，或者要自己部署和维护的服务端。CloudBridge 只是一个安装即用的应用：账单从服务商直接到你磁盘上的文件，不经过别的地方。

CloudBridge vs OptScale（英文）

  • 没有 CloudBridge 账号，没有同步服务，不上报任何数据。
  • 只读：不会创建或修改任何云资源。
  • 它是给一个人看账单用的。需要共享看板和权限角色的团队，更适合用 FinOps 服务端产品。
  • 基于 MIT 许可开源。

常见问题

大家常问的问题

把多家云的费用放在一起看，需要部署服务器吗？

不需要。CloudBridge 是 macOS 和 Windows 上的桌面应用，用只读凭据读取各家云的账单，存进你磁盘上的一个 DuckDB 文件。不用搭服务器、数据库，也不用注册账号。

CloudBridge 支持哪些云？

AWS、Microsoft Azure、Google Cloud、阿里云和 Cloudflare 通过各自的账单 API 或导出接入，火山引擎通过账单导出接入。OpenAI、Anthropic 和 DeepSeek 这些模型平台的账单也记在同一本账里。

不同币种的账单怎么加在一起？

合计按一种报表货币显示。每笔费用都在换算后的金额旁边保留原始币种；没有汇率的费用会明确提示未计入，而不是随便假设一个汇率。

FOCUS 是什么，在这里有什么用？

FOCUS 是 FinOps 基金会制定的开放账单数据规范。CloudBridge 的列名沿用它，所以阿里云的 ECS 和 AWS 的 EC2 都归为 Compute，一条 SQL 就能查所有云。账本也可以导出为 FOCUS CSV。

CloudBridge 是给整个团队用的 FinOps 平台吗？

不是。它是一个人电脑上的一本账，没有同步，也没有共享的服务器。如果组织需要共享看板和权限角色，FinOps 服务端产品更合适；CloudBridge vs OptScale 这篇文章对比了两者。

读取账单本身要花钱吗？

只有服务商收费的地方才会：AWS 的 Cost Explorer 请求和 S3 读取，以及 Google Cloud 超出每月免费额度的 BigQuery 查询。CloudBridge 每个刷新间隔最多请求每家服务商一次，默认 24 小时。
