失控当天就知道，不用等发票

在发票到来之前，先收到费用告警

CloudBridge 把 AWS、阿里云、Cloudflare 和各家模型平台的账单按天读进你电脑上的一本账，在账本上跑告警规则，花费一突增就从状态栏发出通知。

免费开源，支持 macOS 和 Windows。无需注册，不同步，不上报任何数据。

为什么总是月底才知道

天价账单总是意外，因为三件事凑在一起

按量计费没有上限，账单比用量晚，真正失控的项目往往没人盯着。

  1. 没有上限

    按量付费的账号用多少收多少。程序出错时往往不是崩溃，而是一直成功、一直计费。

  2. 账单有延迟

    用量要先汇总、定价才进账单。Cost Explorer 可能滞后一天左右，发票更是一个月才一张。

  3. 没人盯着

    线上服务有监控。测试项目和被遗忘的原型没有流量，也就没人去看它的图表。

告警规则

每种失控，都有对应的规则

默认启用三条规则。给重要的账号加上预算规则，异常规则也可以限定到某一个账号。

场景用哪条规则默认值
平时花费稳定的服务突然翻倍费用增长异常，和该服务自己过去 7 天的基线比连续 2 天超过 2.5 倍
沉睡的项目突然跑起来，或新上线的东西失控账号预算，按月底预测计算需要先给账号设月度预算
预付费余额被快速消耗，比如 DeepSeek余额下限200，按余额自身的币种；设了预算则以预算为准
新出现的花费没人认领未打标签花费占比超过 15% 且比上个月高

持续盯着

关掉窗口，它也在盯着

在 macOS 和 Windows 上，CloudBridge 留在状态栏，标题就是本月花费。每个账号过了刷新间隔（默认 24 小时，最短可设 6 小时）就拉取一次，跑完规则，有新告警就发系统通知。打开开机启动，重启电脑后也照常运行。

状态栏与后台运行

  • 账单按天读取，突增第二天就能看到，不用等到月底。
  • Cloudflare 的每日账单可以拆到具体的 R2 bucket、Worker、D1 数据库和 Durable Object。
  • 每 15 分钟在本地检查一次有没有该刷新的账号，这个检查不会请求任何云平台。
  • 每个服务商每个刷新间隔最多请求一次，盯得再紧也不会多花 API 费用。

隐私

你的账单只留在你的电脑上

账单记录了你在跑什么、为谁跑。CloudBridge 把账本存成你磁盘上的一个 DuckDB 文件，凭据存在系统钥匙串里，对服务商只读不写。

  • 没有 CloudBridge 账号，没有同步服务，不上报任何数据。
  • 只用只读凭据，不会创建或修改任何云资源。
  • 基于 MIT 许可开源。

常见问题

大家常问的问题

CloudBridge 多快能发现费用突增？
一两天之内。账单是按天读取的，服务商报出当天的用量、下一次刷新运行之后，突增就会出现在账本里，不用等到月底的发票。它不是实时监控。
要一直开着 CloudBridge 才能收到告警吗？
需要它在运行，但不需要开着窗口。在 macOS 和 Windows 上它会留在状态栏，每个账号每个刷新间隔拉取一次，有新告警就发系统通知。打开开机启动后，重启电脑也照常运行。
从零突然失控的项目也能发现吗？
能，用基于月底预测的账号预算规则。异常规则拿一个服务和它自己过去七天比，一分钱没花过的服务没有基线；月底预测会把第一天的高额花费外推到本月剩下的日子。
盯着账单本身会产生费用吗？
只有 AWS 会：Cost Explorer 按请求收费，S3 按读取收费。CloudBridge 每个账号每个刷新间隔只拉取一次，默认每个 AWS 账号每天大约两次 Cost Explorer 请求，同样的数据不会付两次钱。
