把云和 AI 账单
放到一起看

CloudBridge 是一个桌面应用，可以汇总 AWS、Azure、Google Cloud、阿里云、Cloudflare、OpenAI、Anthropic 和 DeepSeek 的账单，显示钱花在了哪里，并在费用突然上涨时提醒你。所有数据都保存在本地。

下载 Mac 版 在线试用

免费开源。无需注册，不同步，不上报任何数据。也有 Windows 版。

  • 数据用 DuckDB 存在本地
  • 在菜单栏接收告警
  • 支持 macOS 和 Windows
  • 开源（MIT 许可）

三步开始使用

安装应用后，按下面三步操作。不需要服务器，也不需要注册账号。

  1. 添加账号

    有账单 API 的服务商，填一个只读密钥；只能导入文件的，填个名称就行。密钥保存在系统钥匙串里。

  2. 导入账单

    可以从服务商直接获取，也可以导入下载好的账单文件。两种方式的数据格式相同，列名采用 FOCUS 标准。

    • APIAWS 2026-10127 charges

  3. 查看费用并设置告警

告警

关闭窗口后，告警照常工作

关闭窗口后，CloudBridge 会留在菜单栏（Windows 上是通知区域），并显示本月花费。它会定期刷新每个账号（默认一天一次）并检查告警规则，触发时发送通知。打开“登录时启动”后，电脑重启也会自动运行。

查看每个 bucket、Worker 和 Durable Object 的费用

数据

所有账单使用同一套列

无论账单来自哪里，都会以相同的格式保存，列名采用 FinOps 的 FOCUS 标准，每笔费用同时保留原币种和换算后的金额。比如阿里云 ECS 实例和 AWS EC2 实例都归类为 Compute，也可以直接用 SQL 查询。

SQL 查询 成本归属 模型

SELECT provider, service_category,
       round(sum(billed_cost), 2) AS cost
FROM v_charge_normalized
WHERE billing_period = '2026-10'
GROUP BY ALL ORDER BY cost DESC;

隐私

账单只保存在你的电脑上

账单里能看出你运行了什么、为谁运行、花了多少钱。CloudBridge 把这些数据都保存在本地。

  • 账单保存在你硬盘上的一个 DuckDB 文件里，不经过任何其他服务器。
  • 没有账号系统和同步服务，也不收集使用数据。
  • 凭据保存在 macOS 钥匙串或 Windows 凭据管理器里。
  • 只读取数据，不会创建或修改服务商那边的任何资源。
  • 每个刷新间隔内最多请求每个服务商一次，已付费的数据不会重复获取。
  • 以 MIT 许可开源，代码可以公开查看。

使用场景

常见使用场景

  • 云费用异常告警AWS、Cloudflare 或 AI API 的费用突然上涨时及时收到提醒，不用等到收到账单。
  • 多云成本看板把 AWS、Azure、Google Cloud、阿里云和 Cloudflare 的账单记在一本账里，不用部署服务器。
  • Cloudflare 费用拆分看清 Cloudflare 账单背后是哪个 Worker、R2 bucket、D1 数据库或 Durable Object 在花钱。
  • 大模型 API 成本统计用已有的导出文件，查看 OpenAI、Anthropic、DeepSeek 和百炼各个模型的 token 成本。

FAQ

常见问题

CloudBridge 是什么？

一个免费开源的桌面应用，通过服务商的账单 API 或下载的账单文件，把云平台和 AI 服务商的账单汇总到你电脑上的数据库里。它可以显示各项费用、检查告警规则，关闭窗口后还会继续在菜单栏运行。

支持哪些平台？

AWS（Cost Explorer，或存在 S3 里的 FOCUS 格式 Data Export）、Azure（Cost Management）、阿里云和 Cloudflare 通过账单 API 接入；Google Cloud 通过 BigQuery 账单导出接入；DeepSeek 通过余额 API 接入；阿里云、火山引擎、OpenAI、Anthropic 和 DeepSeek 还可以导入账单文件。

CloudBridge 会把我的账单传到别处吗？

不会。账单从服务商直接保存到你电脑上的 DuckDB 文件。CloudBridge 没有账号系统和同步服务，也不收集使用数据，凭据保存在系统钥匙串里。

使用 CloudBridge 会产生额外费用吗？

只有 AWS 会：Cost Explorer 按请求收费，S3 读取也收费。CloudBridge 在每个刷新间隔（默认 24 小时）内最多请求每个服务商一次，每个 AWS 账号每天大约两次 Cost Explorer 请求。已付费的数据不会重复获取，没有变化的 S3 导出也不会重新下载。其他 API 都是免费的，它也不会创建或修改任何资源。

它怎么发现费用异常？

它按天读取账单，所以费用突增第二天就能在数据里看到。规则会检查费用是否超过近期基线、是否超预算、余额是否过低。只要 CloudBridge 在运行（窗口关闭也算），每个账号每天刷新一次，每条告警都会发送系统通知。Cloudflare 的账单还能细分到 bucket、Worker 或 Durable Object。

支持哪些系统？

Apple 芯片的 macOS（已签名并公证）和 64 位 Windows。Linux 和 Intel Mac 可以从源码自行编译。

CloudBridge 免费吗？

免费。它以 MIT 许可开源，完整源码在 GitHub 上。服务商的 API 费用（如果有）另算。

不安装能试用吗？

可以。浏览器演示运行的是编译成 WebAssembly 的同一个应用，使用涵盖多家服务商、十二个月的示例账单。
