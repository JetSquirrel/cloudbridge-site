持续盯着

窗口关了，它还在盯着

花费告警只有在钱还在往外流的时候才有用。关掉窗口后，CloudBridge 会留在菜单栏（Windows 上是通知区域），标题就是本月花费。每个账号过了刷新间隔（默认一天）才拉取一次，随后跑一遍告警规则，有规则触发就通知你。打开“登录时启动”，重启电脑后它也会自己回到菜单栏。

拆到资源

是哪个 bucket、哪个 Worker、哪个 Durable Object

Cloudflare 的账单只会写“10 月 3 日 R2 Class B 操作 734 次”，从不告诉你是哪个 bucket。CloudBridge 会去 Cloudflare 的分析接口查每个资源当天的用量占比，按比例把账单拆下去，失控的命名空间会直接以名字出现。免费额度内的用量也会记下来：失控往往就是从这里开始的，比第一笔扣费早好几天。

一本账

每份账单，同一套列

不管账单从哪条路进来，落进账本的都是同样的行，列名沿用 FinOps 的 FOCUS 规范，每笔费用的原始币种和换算后的金额并排保留。所以阿里云的 ECS 实例和 AWS 的 EC2 实例都算作 Compute，账本里的问题直接用 SQL 来问。

SQL 查询 成本归属 模型

SELECT provider, service_category,
       round(sum(billed_cost), 2) AS cost
FROM v_charge_normalized
WHERE billing_period = '2026-10'
GROUP BY ALL ORDER BY cost DESC;

隐私

你的账单只属于你

一份账单能看出你在跑什么、为谁跑、花了多少。CloudBridge 把这些都留在你的电脑上。

  • 账本是你硬盘上的一个 DuckDB 文件，账单从不经过任何第三方服务器。
  • 没有账号体系，没有同步服务，不上报任何数据。
  • 凭据存放在 macOS 钥匙串或 Windows 凭据管理器里。
  • 只读不写：从不创建或修改服务商那边的任何资源。
  • 每个刷新间隔最多向每个服务商请求一次，同样的数据从不付两次钱。
  • 以 MIT 许可开源，每一行代码都可以看。

常见问题

大家常问的

CloudBridge 是什么？
一个免费开源的桌面应用。它把你在各家云平台和 AI 服务商的账单读进你电脑上的一本账——要么通过服务商的账单 API，要么用你下载的账单导出文件——然后画出钱花在了哪里。它会在这本账上跑告警规则，窗口关掉后还会在菜单栏里继续盯着。
支持哪些平台？
AWS（Cost Explorer，或存在 S3 里的 FOCUS 格式 Data Export）、阿里云和 Cloudflare 通过账单 API 接入；DeepSeek 通过余额 API 接入；阿里云、火山引擎、OpenAI、Anthropic 和 DeepSeek 还可以导入账单文件。暂不支持 Azure 和 Google Cloud。
CloudBridge 会把我的账单传到别处吗？
不会。账单从服务商直接写进你电脑上的一个 DuckDB 文件。CloudBridge 没有账号体系，没有同步服务，也不上报任何数据，凭据存放在系统钥匙串里。
CloudBridge 自己会让我的账单变多吗？
只有 AWS 会产生费用：Cost Explorer 按请求收费，S3 读取也收费。CloudBridge 每个刷新间隔（默认 24 小时）最多向每个服务商请求一次，每个 AWS 账号一天大约两次 Cost Explorer 请求；已经付过费的拉取不会重复，没有变化的 S3 导出也不会重新下载。它调用的其他 API 都免费，而且从不创建或修改任何资源。
它怎么发现账单失控？
它按天读取账单，所以花费一飙升，第二天就进了账本，不用等月底发票。规则会标出超过近期基线的花费、预算和余额过低；CloudBridge 运行期间（包括窗口关掉、只留在菜单栏的时候）每个账号每天刷新一次，每条告警都会发系统通知。Cloudflare 的账单还能拆到背后具体的 bucket、Worker 或 Durable Object。
支持哪些系统？
Apple 芯片的 macOS（已签名并公证）和 64 位 Windows。Linux 和 Intel Mac 可以从源码自行编译。
CloudBridge 免费吗？
免费。它以 MIT 许可开源，完整源码在 GitHub 上。服务商的 API 费用（如果有的话）另算。
不安装能先试试吗？
能。同一套应用可以编译成 WebAssembly，在浏览器演示站里运行，用的是一份涵盖多家服务商、长达十二个月的示例账单。
