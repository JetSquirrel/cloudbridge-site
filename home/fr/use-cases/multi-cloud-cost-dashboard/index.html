Un seul format

Toutes les factures dans les mêmes colonnes

Les factures sont stockées avec les noms de colonnes de la norme FinOps FOCUS, quelle que soit leur provenance. Une instance ECS d’Alibaba Cloud et une instance AWS EC2 comptent toutes deux comme Compute, et une seule requête SQL couvre tous les fournisseurs.

Requête FOCUS et données de jetons

  • Des colonnes comme billed_cost, effective_cost, service_category et region_id ont le même sens pour chaque source.
  • Les totaux sont dans une seule devise de restitution ; chaque ligne conserve sa devise d’origine à côté du montant converti.
  • Les crédits, les remboursements et les achats ponctuels restent ce qu’ils sont et ne sont pas ajoutés à l’usage.
  • Le registre est un fichier DuckDB que vous pouvez interroger en SQL en lecture seule ou exporter en CSV FOCUS.

Qui a dépensé, et pour quoi

La vue d’ensemble montre le mois à ce jour, la prévision et les plus fortes variations sur toutes les sources. L’attribution rattache les dépenses à vos lignes métier et les décompose par étiquette, service, région ou catégorie de service FOCUS.

Vue d’ensemble Attribution Rapprochement

  • Les règles d’alerte s’exécutent sur le même registre : anomalies de coûts, budgets de compte, seuils de solde et dépenses sans étiquette. Alertes de coûts cloud.
  • Les factures de fournisseurs de modèles côtoient les clouds, avec le coût par million de jetons et par modèle. Suivi des coûts d’API LLM.
  • Le rapprochement compare la facture finale de chaque fournisseur avec le registre, dans la devise de la facture.

Sans serveur

Une application de bureau, pas une plateforme à déployer

La plupart des outils de coûts multi-cloud sont un service hébergé auquel vous envoyez vos factures, ou un serveur à déployer et à maintenir. CloudBridge est une application que vous installez : les factures vont du fournisseur à un fichier sur votre disque, et nulle part ailleurs.

CloudBridge face à OptScale

  • Aucun compte CloudBridge, aucun service de synchronisation, aucune télémétrie.
  • Lecture seule : aucune ressource du fournisseur n’est créée ni modifiée.
  • Pensée pour la vue des factures d’une seule personne. Une équipe qui a besoin de tableaux de bord partagés et de rôles préférera un serveur FinOps.
  • Open source sous licence MIT.

FAQ

Questions fréquentes

Faut-il déployer un serveur pour voir tous mes coûts cloud ensemble ?

Non. CloudBridge est une application de bureau pour macOS et Windows. Elle lit chaque fournisseur avec un identifiant en lecture seule et conserve les factures dans un fichier DuckDB sur votre disque. Il n’y a ni serveur, ni base de données, ni compte à mettre en place.

Quels clouds CloudBridge lit-elle ?

AWS, Microsoft Azure, Google Cloud, Alibaba Cloud et Cloudflare via leurs API ou exports de facturation, et Volcengine via son export de factures. Les factures de fournisseurs de modèles d’OpenAI, Anthropic et DeepSeek arrivent dans le même registre.

Comment additionne-t-elle des factures dans des devises différentes ?

Les totaux sont affichés dans une seule devise de restitution. Chaque ligne conserve sa devise d’origine à côté du montant converti, et une ligne sans taux de change est signalée comme écartée plutôt que supposée.

Qu’est-ce que FOCUS, et pourquoi est-ce important ici ?

FOCUS est la spécification ouverte de la FinOps Foundation pour les données de facturation. CloudBridge nomme ses colonnes d’après elle : une instance ECS d’Alibaba Cloud et une instance AWS EC2 comptent donc toutes deux comme Compute, et une seule requête SQL couvre tous les fournisseurs. Le registre peut aussi être exporté en CSV FOCUS.

CloudBridge est-elle une plateforme FinOps pour toute une équipe ?

Non. C’est un registre sur l’ordinateur d’une personne, sans synchronisation ni serveur partagé. Si une organisation a besoin de tableaux de bord partagés et de rôles, un serveur FinOps convient mieux ; l’article CloudBridge face à OptScale compare les deux.

Lire les factures coûte-t-il quelque chose ?

Uniquement là où le fournisseur le facture : les requêtes Cost Explorer et les lectures S3 sur AWS, et les requêtes BigQuery de Google Cloud au-delà du palier gratuit mensuel. CloudBridge contacte chaque fournisseur au plus une fois par intervalle d’actualisation, 24 heures par défaut.
