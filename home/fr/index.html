Télécharger

Toutes vos factures cloud et IA au même endroit.

CloudBridge est une application de bureau qui rassemble vos factures AWS, Azure, Google Cloud, Alibaba Cloud, Cloudflare, OpenAI, Anthropic et DeepSeek, montre ce que vous payez et vous alerte lorsque les coûts s’envolent. Tout est stocké sur votre ordinateur.

Télécharger pour Mac Essayer la démo

Gratuit et open source. Sans inscription, sans synchronisation, sans télémétrie. Aussi pour Windows.

  • Données stockées localement dans DuckDB
  • Alertes depuis la barre de menus
  • macOS et Windows
  • Open source (MIT)

Premiers pas

Démarrez en trois étapes

Installez l’application, puis suivez ces étapes. Aucun serveur ni compte n’est nécessaire.

  1. Ajouter un compte

    Saisissez une clé d’API en lecture seule pour les fournisseurs dotés d’une API de facturation, ou simplement un nom si vous importez des fichiers. Les clés sont enregistrées dans le trousseau de votre système.

  2. Importer vos factures

    CloudBridge peut récupérer les factures auprès du fournisseur, ou vous pouvez importer un fichier que vous avez téléchargé. Les deux aboutissent au même format, avec les noms de colonnes de la norme FOCUS.

    • APIAWS 2026-10127 lignes
    • APICloudflare 2026-1014 lignes
    • FichierOpenAI 2026-09412 lignes

  3. Suivez les coûts et définissez des alertes

    Décomposez les dépenses par compte, service, modèle ou ligne métier. Vous recevrez une notification lorsqu’un coût s’envole.

Vous voulez d’abord jeter un œil ? Une vue d’ensemble vide propose Charger des données de démonstration, ou vous pouvez essayer la démo dans le navigateur avec une facture d’exemple.

Sous Windows, l’installateur n’est pas signé numériquement, SmartScreen affichera donc probablement un avertissement. Consultez Premiers pas pour savoir quoi faire.

Alertes

Les alertes continuent après la fermeture de la fenêtre

Lorsque vous fermez la fenêtre, CloudBridge reste dans la barre de menus et affiche les dépenses du mois. Il actualise chaque compte selon un calendrier (une fois par jour par défaut), vérifie vos règles d’alerte et envoie une notification si l’une est déclenchée. Activez « Ouvrir à la connexion » pour qu’il continue de tourner après un redémarrage.

Coût par ressource

Voyez ce que coûte chaque bucket, Worker et Durable Object

La facture Cloudflare peut indiquer « opérations R2 Classe B, 734 le 3 octobre » sans nommer le bucket. CloudBridge récupère l’usage quotidien de chaque ressource depuis les analytics de Cloudflare et répartit le coût entre elles, pour que vous voyiez laquelle est responsable. Il enregistre aussi l’usage effectué dans l’allocation gratuite, car un problème de coût peut commencer là avant que quoi que ce soit ne vous soit facturé.

Données

Toutes les factures utilisent les mêmes colonnes

Les factures sont stockées dans le même format, quelle que soit leur provenance, avec les noms de colonnes de la norme FinOps FOCUS. Chaque ligne conserve sa devise d’origine à côté du montant converti. Par exemple, une instance ECS d’Alibaba Cloud et une instance AWS EC2 comptent toutes deux comme Compute, et vous pouvez tout interroger en SQL.

Confidentialité

Vos factures restent sur votre ordinateur

Les factures montrent ce que vous exploitez, pour qui et à quel prix. CloudBridge garde tout cela sur votre ordinateur.

  • Les factures sont stockées dans un fichier DuckDB sur votre disque et ne passent par aucun autre serveur.
  • Aucun compte, aucun service de synchronisation et aucune télémétrie.
  • Les identifiants sont stockés dans le trousseau macOS ou le gestionnaire d’identifiants Windows.
  • Lecture seule : il ne crée ni ne modifie quoi que ce soit chez votre fournisseur.
  • Il contacte chaque fournisseur au plus une fois par intervalle d’actualisation et ne paie jamais deux fois les mêmes données.
  • Open source sous licence MIT, pour que vous puissiez lire le code.

FAQ

Questions fréquentes

Qu’est-ce que CloudBridge ?

Une application de bureau gratuite et open source qui rassemble vos factures de fournisseurs cloud et d’IA dans une base de données sur votre ordinateur, via l’API de facturation de chaque fournisseur ou un fichier que vous avez téléchargé. Elle montre ce que vous payez, vérifie vos règles d’alerte et continue de tourner dans la barre de menus après la fermeture de la fenêtre.

Quels fournisseurs prend-elle en charge ?

AWS (Cost Explorer, ou un Data Export FOCUS dans S3), Azure (Cost Management), Alibaba Cloud et Cloudflare via leurs API de facturation ; Google Cloud via son export de facturation BigQuery ; DeepSeek via son API de solde ; et les exports de factures d’Alibaba Cloud, Volcengine, OpenAI, Anthropic et DeepSeek.

CloudBridge envoie-t-elle mes factures quelque part ?

Non. Les factures vont directement du fournisseur à un fichier DuckDB sur votre ordinateur. Il n’y a ni compte CloudBridge, ni service de synchronisation, ni télémétrie, et les identifiants sont stockés dans le trousseau de votre système.

CloudBridge va-t-elle augmenter ma facture ?

Uniquement sur AWS, où Cost Explorer facture chaque requête et S3 facture les lectures. CloudBridge contacte chaque fournisseur au plus une fois par intervalle d’actualisation (24 heures par défaut), soit environ deux requêtes Cost Explorer par compte AWS et par jour. Elle ne répète pas une récupération déjà payée et ne télécharge pas deux fois un export S3 inchangé. Les autres API qu’elle appelle sont gratuites, et elle ne crée ni ne modifie jamais une ressource.

Comment détecte-t-elle les pics de coûts ?

Elle lit les factures jour par jour : un pic apparaît donc dans les données le lendemain. Les règles vérifient les dépenses au-dessus de leur référence récente, les budgets et les soldes bas. Tant que CloudBridge tourne, même fenêtre fermée, elle actualise chaque compte une fois par jour et envoie une notification pour chaque alerte. Les factures Cloudflare peuvent aussi être réparties jusqu’au bucket, au Worker ou au Durable Object.

Sur quels systèmes fonctionne-t-elle ?

macOS sur Apple silicon (signé et notarié) et Windows 64 bits. Linux et les Mac Intel peuvent la compiler depuis les sources.

CloudBridge est-elle gratuite ?

Oui. Elle est gratuite et open source sous licence MIT, avec le code source complet sur GitHub. Les éventuels frais d’API des fournisseurs sont à part.

Puis-je l’essayer sans l’installer ?

Oui. La démo dans le navigateur exécute la même application, compilée en WebAssembly, sur une facture d’exemple couvrant douze mois et plusieurs fournisseurs.
